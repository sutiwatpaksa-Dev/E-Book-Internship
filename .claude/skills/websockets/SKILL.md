# Realtime / WebSockets

## ข้อจำกัดของเว็บนี้ (อ่านก่อนเสนออะไร)

- API ของเว็บรันเป็น Vercel Function (Hono บน Bun ผ่าน `src/app/api/[[...route]]/route.ts`) **ซึ่งเปิดการเชื่อมต่อค้างไว้นานไม่ได้** จึงทำ WebSocket server ตรงนี้ไม่ได้
- ตอนนี้เว็บใช้ polling: `src/hooks/use-polling.ts` ถามซ้ำเฉพาะตอนแท็บเปิดอยู่ และถามทันทีเมื่อกลับมาที่แท็บ แชทใช้รอบละ 20 วินาที
- เนื้อหาที่สอนเรื่องนี้อยู่ใน `content/docs/05-http-api.mdx` (ตาราง Polling / SSE / WebSocket / Webhook และหลัก "เลือกแบบเบาที่สุดที่พอ")

## เลือกแบบไหน

| ต้องการ | เลือก | บนเว็บนี้ |
|---|---|---|
| ช้าไปสัก 10–20 วินาทีก็ได้ | Polling | ใช้อยู่แล้ว ปรับ `ms` หรือส่ง `since` ไปเพื่อดึงเฉพาะของใหม่ |
| server ส่งมาทางเดียว (แจ้งเตือน, ความคืบหน้า) | SSE | ทำได้แค่ช่วงสั้นๆ ตามเวลาสูงสุดของ function ต้องรองรับการต่อใหม่ |
| คุยสองทางถี่ๆ (พิมพ์อยู่..., เกม, แก้เอกสารพร้อมกัน) | WebSocket | ต้องใช้บริการภายนอก (เช่น Pusher, Ably, Supabase Realtime) หรือแยก server ที่รันค้างได้ |
| ระบบอื่นแจ้งเรามา | Webhook | route `POST` ธรรมดาใน `server/routes/` ต้องตรวจลายเซ็น |

ก่อนเสนอ WebSocket ต้องตอบให้ได้ว่า polling ไม่พอเพราะอะไร และบอกค่าใช้จ่ายของบริการภายนอกด้วย บริการใหม่หรือบัญชีใหม่ต้องให้ผู้ใช้ตัดสิน

## ถ้าทำจริง

- โค้ดยังต้องตามชั้นของ repo: การเชื่อมต่ออยู่ใน `src/hooks/` (เช่น `use-realtime.ts`) component ไม่ต่อเอง ฝั่ง server ให้ service เป็นตัว publish event หลังบันทึก DB เสร็จ (DB เป็นความจริงหลัก realtime แค่บอกว่ามีของใหม่)
- ตรวจสิทธิ์ทุกช่องทาง: น้องเห็นได้แค่ thread ของตัวเอง พี่เลี้ยงเห็นทุก thread (เหมือนกฎใน `thread.service.ts`)
- ต้องมีทางสำรอง: ถ้าหลุดให้กลับไปใช้ polling, ต่อใหม่แบบเว้นช่วงห่างขึ้นเรื่อยๆ (backoff) และดึงของที่พลาดไปจาก REST
- ห้ามใส่ token หรือ secret ไว้ใน URL

## ถ้าเขียนเป็นเนื้อหาสอน

- เริ่มจากเหตุผลว่าทำไมต้องใช้ realtime (เทียบกับโทรถามร้านซ้ำๆ กับร้านโทรมาบอกเอง)
- ให้เริ่มทำ polling ก่อน แล้วค่อยขยับไป SSE และ WebSocket โดยบอกว่าแต่ละแบบแลกกับอะไร
- ตัวอย่าง WebSocket ฝั่ง Hono ใช้ helper ของ runtime (`hono/bun` → `upgradeWebSocket`) ให้ตรวจ API ปัจจุบันจากเอกสารทางการของ Hono ก่อนเขียน และระบุว่ารันบน Vercel Function ไม่ได้
- ทุกคำสั่งมีทั้งแบบ Windows และ Mac และอ้างอิง MDN หรือเอกสารทางการ
