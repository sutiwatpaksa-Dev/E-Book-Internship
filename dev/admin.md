# ⚙️ จัดการบัญชี

สำหรับพี่เลี้ยง (role **Dev**) เพิ่มบัญชีน้อง ออก PIN ใหม่ ปลดล็อก ปิดบัญชี และอัปโหลดไฟล์ Requirement

- **PIN แสดงครั้งเดียว** ตอนสร้างหรือออกใหม่ ระบบเก็บแค่ hash จึงดูย้อนหลังไม่ได้ ถ้าน้องลืมให้กด "ออก PIN ใหม่"
- **กรอก PIN ผิด 5 ครั้ง** บัญชีจะล็อก 15 นาที กดปลดล็อกได้ทันทีที่นี่
- **ปิดบัญชีแล้ว** น้องเรียก API (เช่นเปิด PDF) ไม่ได้ทันที แต่หน้า STARTER ที่ล็อกด้วยบัตรผ่านจะเปิดได้จนบัตรหมดอายุ (ไม่เกิน 12 ชั่วโมง)
