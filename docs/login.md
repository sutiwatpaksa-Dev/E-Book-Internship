# 🔑 เข้าสู่ระบบ

ส่วน **Mini Project STARTER** และเอกสาร Requirement เปิดให้เฉพาะน้องฝึกงานและพี่เลี้ยงของบริษัท
ใช้ username และ PIN ที่พี่เลี้ยงให้ไว้ ยังไม่มีบัญชีหรือลืม PIN ให้ติดต่อพี่เลี้ยง

<LoginForm />

> 🔒 **ทำไมต้อง login:** เอกสาร Requirement เป็นโจทย์ที่บริษัทใช้กับลูกค้าจริง จึงไม่เปิดให้คนนอกอ่าน ส่วนเนื้อหาบทเรียนทั่วไปยังอ่านได้ทุกคนโดยไม่ต้อง login
> ระบบหน้านี้สร้างจากเรื่องเดียวกับที่สอนใน [บทที่ 15](./15-auth.md): เก็บ PIN แบบ hash, cookie แบบ httpOnly และตรวจสิทธิ์ฝั่ง server
