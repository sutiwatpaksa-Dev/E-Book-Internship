## เกณฑ์ประเมิน (100 คะแนน)

| หัวข้อ | คะแนน | ดูอะไร |
|---|---|---|
| ฐานข้อมูล | 15 | schema สมเหตุสมผล, FK/unique ถูก, migration รันได้ |
| Backend / API | 25 | ครบตาม spec, Zod ทุก endpoint, status code ถูก, auth ปลอดภัย |
| หน้าบ้าน | 20 | ครบ 3 หน้า, ดึงจาก API จริง, responsive, loading/error |
| หลังบ้าน | 20 | CRUD ครบ, แก้แล้วหน้าบ้านเปลี่ยนจริง, ใช้ง่าย |
| SEO / Security | 10 | meta tags, OG, rate limit, cookie ปลอดภัย |
| Code + README + Demo | 10 | อ่านง่าย, ไม่มี `any` มั่ว, ตอบคำถามโค้ดตัวเองได้ |

> ⚠️ **ผ่าน = 70 คะแนนขึ้นไป** และต้องไม่มีข้อต่อไปนี้ (มีข้อใดข้อหนึ่ง = **ไม่ผ่านทันที**)
> - ❌ รหัสผ่านเก็บแบบไม่ hash
> - ❌ admin API เรียกได้โดยไม่ login
> - ❌ โปรเจกต์รันตาม README ไม่ขึ้น
