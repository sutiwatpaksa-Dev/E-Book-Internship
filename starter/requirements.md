# STARTER: Requirement หน้าบ้าน + หลังบ้าน 🖥️

> **⚡ สรุป 30 วินาที**
> - หน้าบ้าน 3 หน้า: **Home `/`**, **About/Services `/about`**, **Contact `/contact`**
> - ทุกข้อความ รูป และรายการบนหน้าบ้าน **ต้องดึงจาก API** ห้าม hardcode
> - หลังบ้านอยู่ที่ `/admin` เข้าได้เฉพาะคนที่ login แล้ว ต้อง **ใช้ง่ายสำหรับเจ้าของร้านที่ไม่รู้เรื่องโค้ด**

---

## 1. หน้าบ้าน (Public)

ทุกข้อความ รูป และรายการบนหน้าบ้าน **ต้องดึงจาก API** ห้าม hardcode ในโค้ด (ยกเว้นข้อความ UI เช่น ปุ่ม "ส่ง")

> 💡 **ทำไม?** ถ้า hardcode เจ้าของร้านแก้เองไม่ได้ ต้องโทรหา dev ทุกครั้ง ซึ่งขัดกับฟีเจอร์ "ระบบจัดการเนื้อหา" ที่ขายไป

### ส่วนที่ใช้ร่วมทุกหน้า
- **Navbar:** โลโก้, เมนู 3 หน้า, ไฮไลต์หน้าที่อยู่, มือถือเป็น hamburger menu
- **Footer:** ที่อยู่, เบอร์โทร, เวลาทำการ, ไอคอน social
- **ปุ่ม LINE ลอยมุมขวาล่าง** (floating) ลิงก์ตามที่ตั้งในหลังบ้าน

### หน้า 1: Home `/`
- **Hero:** หัวข้อใหญ่ ข้อความรอง รูปพื้นหลัง ปุ่ม call-to-action ไปหน้า Contact
- แสดงบริการ/สินค้าเด่น **3 รายการ** (ที่ admin ติ๊ก "แสดงหน้าแรก")
- จุดเด่นของร้าน **3–4 ข้อ** (ไอคอน + ข้อความ)

### หน้า 2: About / Services `/about`
- เกี่ยวกับร้าน: เนื้อหายาว + รูป
- รายการบริการ/สินค้าทั้งหมด แสดงเป็น card: รูป, ชื่อ, รายละเอียดสั้น, ราคา (ถ้ามี)
- กรองตามหมวดหมู่ได้ (อย่างน้อย 2 หมวด)

### หน้า 3: Contact `/contact`
- ฟอร์ม: ชื่อ\*, เบอร์โทร\*, อีเมล, หัวข้อ, ข้อความ\* (\* = บังคับ)
- validate ฝั่ง client ก่อนส่ง และแสดง error ใต้ช่องที่ผิด
- ระหว่างส่ง ปุ่มต้อง **disable + แสดง loading**, ส่งสำเร็จแสดงข้อความขอบคุณและล้างฟอร์ม
- แสดงข้อมูลติดต่อ + แผนที่ Google Maps (embed iframe จากลิงก์ที่ admin ตั้ง)

### สถานะที่ต้องมีทุกหน้า
- ⏳ **Loading** (skeleton หรือ spinner) ระหว่างรอ API
- 💥 **Error** เมื่อ API ล่ม ไม่ใช่หน้าขาว
- 🚫 **หน้า 404** เมื่อเข้า URL ที่ไม่มี

> 📚 ตัวอย่างโค้ด: Navbar/Hero/ปุ่ม LINE [บทที่ 12](../12-tailwind.md), Route/404/filter [บทที่ 13](../13-router-seo.md), ฟอร์ม [บทที่ 11 ข้อ 7](../11-react.md)

> ⚠️ **กับดัก:** ทดสอบแค่ตอน API ทำงานปกติ ลองปิด server แล้วเปิดหน้าเว็บดู ถ้าเห็นหน้าขาว = ยังไม่ผ่าน

## 2. หลังบ้าน (Admin)

หลังบ้านอยู่ที่ `/admin` เข้าได้เฉพาะคนที่ login แล้ว ไม่ต้องสวยเท่าหน้าบ้าน แต่ต้อง **ใช้งานง่ายสำหรับเจ้าของร้านที่ไม่รู้เรื่องโค้ด**

### 2.1 Login `/admin/login`
- กรอกอีเมล + รหัสผ่าน
- ผิดแสดงข้อความ **"อีเมลหรือรหัสผ่านไม่ถูกต้อง"** (ห้ามบอกว่าผิดช่องไหน)
- เข้า `/admin/*` โดยไม่ login ต้องเด้งกลับหน้า login
- มีปุ่ม logout และ session หมดอายุใน 1 วัน

> 🤓 **ทำไมห้ามบอกว่าผิดช่องไหน?** ถ้าบอกว่า "ไม่พบอีเมลนี้" คนร้ายจะรู้ว่าอีเมลไหนมีบัญชีอยู่จริง แล้วไปเดารหัสต่อ ([บทที่ 10: Error ที่บอกมากเกินไป](../10-security.md#📣-error-ที่บอกมากเกินไป))

> 📚 ตัวอย่างโค้ด login / middleware / RequireAuth: [บทที่ 15](../15-auth.md)

### 2.2 Dashboard `/admin`
- จำนวนข้อความติดต่อที่ยังไม่อ่าน
- จำนวนบริการ/สินค้าทั้งหมด
- ข้อความติดต่อล่าสุด 5 รายการ

### 2.3 ตั้งค่าเว็บไซต์ `/admin/settings`
แก้ได้ในฟอร์มเดียว: ชื่อร้าน, โลโก้ (URL), เบอร์โทร, อีเมล, ที่อยู่, เวลาทำการ, ลิงก์ LINE / Facebook / IG, ลิงก์ Google Maps

### 2.4 จัดการเนื้อหาแต่ละหน้า `/admin/pages`
- แก้ข้อความ Hero, จุดเด่น, เนื้อหา About
- แก้ SEO ต่อหน้า: title, meta description, OG image

### 2.5 จัดการบริการ/สินค้า `/admin/services`
- ตารางรายการ: ค้นหาด้วยชื่อ, กรองตามหมวด, แบ่งหน้า 10 รายการ
- เพิ่ม / แก้ไข / ลบ (**ลบต้องถามยืนยันก่อน**)
- ฟิลด์: ชื่อ, หมวดหมู่, รายละเอียด, ราคา, รูป, แสดงหน้าแรก (ใช่/ไม่), เปิด/ปิดการแสดงผล, ลำดับการแสดง
- จัดการหมวดหมู่ได้ (เพิ่ม/แก้/ลบ) **ลบหมวดที่ยังมีสินค้าอยู่ไม่ได้**

### 2.6 ข้อความติดต่อ `/admin/messages`
- รายการข้อความ เรียงใหม่สุดก่อน ตัวที่ยังไม่อ่านเป็นตัวหนา
- กดเปิดดูแล้วเปลี่ยนเป็น "อ่านแล้ว" อัตโนมัติ
- ลบข้อความได้

### 2.7 รูปภาพ
รอบนี้ **ใช้ URL รูป** ไปก่อน (ฝากรูปที่อื่นแล้วเอาลิงก์มาใส่) ไม่ต้องทำระบบอัปโหลด เพราะ 10 วันไม่พอทำให้ดี ใครเสร็จเร็วไปทำในข้อ [Bonus](./submission.md#🎁-bonus)
