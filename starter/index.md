> ⏱ 10 วันทำงาน (ยืดหยุ่นได้) · 👤 ทำคนเดียว · 🧩 ต้องผ่านก่อน: บทที่ 0–16

> **⚡ สรุป 30 วินาที**
> - ทำเว็บไซต์ร้านค้าสมมติ 1 เว็บ ให้ **ครบทั้งร้าน**: หน้าที่ลูกค้าเห็น + หน้าจัดการของเจ้าของร้าน + ที่เก็บข้อมูล

## 1. เลือกร้านและเขียนสรุปร้าน (วันที่ 1)

**ขั้นแรก เลือกร้านสมมติ 1 ประเภท** แล้วเขียนสรุปสั้นๆ (เรียกว่า **brief**) ส่งพี่เลี้ยงก่อนเริ่มเขียนโค้ด
ตัวอย่าง: ร้านกาแฟ ☕, คลินิกทำฟัน 🦷, ร้านซ่อมมือถือ 📱, สตูดิโอถ่ายภาพ 📷, โฮมสเตย์ 🏡, ร้านเช่าชุด 👗

**สรุปร้านต้องมี**
- ชื่อร้าน
- ลูกค้าหลักคือใคร
- สีประจำร้าน 2–3 สี
- โลโก้ (ทำเองง่ายๆ ได้)
- สินค้าหรือบริการ **อย่างน้อย 6 อย่าง**

> ⚠️ **ห้ามเลือก** ร้านที่ต้องมีตะกร้าสินค้าหรือจ่ายเงินออนไลน์ เพราะเกินงบแพ็กเกจ STARTER

## 4. จัดโฟลเดอร์อย่างน้อยแบบนี้

แยกโฟลเดอร์หน้าเว็บ (`client`) กับส่วนเบื้องหลัง (`server`) เหมือนงาน Todo

```
project/
├─ client/                 ← หน้าเว็บ
│  └─ src/
│     ├─ pages/            # แต่ละหน้า (หน้าลูกค้า + หน้าจัดการร้าน)
│     ├─ components/       # ชิ้นส่วนที่ใช้ซ้ำ เช่น ปุ่ม การ์ด เมนู
│     ├─ api/              # ทุกการเรียก server อยู่ที่นี่ที่เดียว
│     └─ types/            # บอกหน้าตาของข้อมูล
├─ server/                 ← ส่วนเบื้องหลัง
│  ├─ src/
│  │  ├─ index.ts          # ไฟล์เริ่มต้น
│  │  ├─ routes/           # แยกไฟล์ตามเรื่อง เช่น บริการ, ข้อความ
│  │  ├─ db/
│  │  │  ├─ schema.ts      # แบบแปลนตาราง
│  │  │  └─ index.ts       # ต่อฐานข้อมูล
│  │  ├─ validators/       # กฎตรวจข้อมูล (Zod)
│  │  └─ middleware/       # ด่านตรวจ เช่น เช็คว่า login หรือยัง
│  ├─ drizzle/             # ไฟล์บันทึกการเปลี่ยนตาราง (migration)
│  └─ .env.example
└─ README.md
```

> ⚠️ **กติกา**
> - ห้ามเอาไฟล์ `.env` (ที่มีรหัสลับ) ขึ้น Git ให้ทำไฟล์ `.env.example` บอกแทนว่าต้องตั้งค่าอะไรบ้าง ([บทที่ 10 ข้อ 1](../10-security.md))
> - ต้องมีคำสั่งสร้างบัญชีเจ้าของร้านคนแรก (seed)
