หน้านี้อธิบายว่าเว็บคู่มือฝึกงาน Blicktech เก็บข้อมูลอะไรไว้ในเบราว์เซอร์ของคุณ เพื่ออะไร และคุณเลือกได้แค่ไหน

> **สรุปสั้น:** ตอนนี้เว็บนี้ใช้เฉพาะคุกกี้ที่จำเป็นต่อการเข้าสู่ระบบ ไม่มีสคริปต์วิเคราะห์ (เช่น Google Analytics) และไม่มีสคริปต์โฆษณา (เช่น Google Ads, Meta Pixel, LINE Tag) ถ้าวันหนึ่งจะเพิ่ม จะโหลดเฉพาะเมื่อคุณยินยอมและแจ้งในหน้านี้ก่อน

## คุกกี้ที่จำเป็น (เปิดเสมอ)

| ชื่อ | เก็บอะไร | อยู่นานแค่ไหน |
|---|---|---|
| `bt_session` | บัตรผ่านหลัง login (ลงลายมือชื่อแล้ว อ่านจาก JavaScript ไม่ได้) | 12 ชั่วโมง หรือจนกด "ออกจากระบบ" |
| `bt_role` | บอกว่าเป็นน้องหรือพี่เลี้ยง เพื่อแสดงเมนูให้ถูก (ไม่ใช่ตัวตัดสินสิทธิ์ สิทธิ์ตรวจที่ server ทุกครั้ง) | 12 ชั่วโมง |

คุกกี้สองตัวนี้ถูกตั้งตอน login เท่านั้น คนที่ไม่ได้ login ไม่มีคุกกี้ของเรา

## ข้อมูลที่จำไว้ในเบราว์เซอร์ (localStorage)

เก็บในเครื่องคุณเท่านั้น ไม่ส่งไปที่ server และไม่ใช้ติดตามตัวตน เพื่อให้หน้าเว็บจำการตั้งค่าของคุณ

| ชื่อ | ใช้ทำอะไร |
|---|---|
| `theme` | จำโหมดสว่าง/มืด |
| `bt-roadmap-done` | จำหัวข้อที่ติ๊กแล้วตอนยังไม่ได้ login |
| `bt-hints` | จำว่าปิดคำแนะนำแล้วหรือยัง |
| `notify.sound` | จำว่าเปิดเสียงแจ้งเตือนไหม |
| `req-viewer-width` | จำความกว้างของแผงเอกสาร Requirement |
| `admin.cohort` | (พี่เลี้ยง) จำรุ่นที่เลือกดูในหลังบ้าน |
| `bt-cookie-consent` | จำคำตอบเรื่องคุกกี้ของคุณ |

## คุกกี้เพื่อการวิเคราะห์และการตลาด

ปัจจุบัน **ไม่มี** ที่เว็บนี้ ตัวเลือกในหน้า "ตั้งค่าคุกกี้" มีไว้เพื่อให้คำตอบของคุณถูกจำไว้แล้ว หากมีการเพิ่มเครื่องมือเหล่านี้ในอนาคต ระบบจะโหลดเฉพาะเมื่อคุณเลือกยอมรับประเภทนั้น และรายชื่อจะถูกเพิ่มในหน้านี้

## เปลี่ยนหรือถอนความยินยอม

กด **ตั้งค่าคุกกี้** ที่ท้ายเว็บไซต์ได้ทุกเมื่อ เพื่อเปลี่ยนคำตอบ ถ้าต้องการลบข้อมูลที่จำไว้ทั้งหมด ให้ล้างข้อมูลเว็บไซต์ในการตั้งค่าเบราว์เซอร์ (จะต้อง login ใหม่)
