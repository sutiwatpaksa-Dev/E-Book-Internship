## 1. Tailwind คืออะไร

**CSS แบบเดิม:** ตั้งชื่อเอง → ไปเขียนการตกแต่งในอีกไฟล์ → สลับไฟล์ไปมา
**Tailwind:** ใช้คำสำเร็จรูปที่แต่ละคำทำอย่างเดียว ต่อกันใน `className` ได้เลย

```tsx
// CSS แบบเดิม
<button className="btn-primary">จองเลย</button>
/* style.css */ .btn-primary { background: #6b3e26; color: white; padding: 8px 16px; border-radius: 8px; }

// Tailwind
<button className="bg-brand text-white px-4 py-2 rounded-lg">จองเลย</button>
```

> **นึกภาพ:** CSS แบบเดิม = สั่งตัดชุดใหม่ทุกครั้ง / Tailwind = **ตัวต่อเลโก้** มีชิ้นมาตรฐานให้ต่อ ขนาดเท่ากันทุกครั้ง

![แต่ละคำใน className ของ Tailwind เทียบเท่า CSS หนึ่งอย่าง](/img/12-utility-classes.svg)
*แต่ละคำทำอย่างเดียว ต่อกันแล้วได้หน้าตาของปุ่ม*

**คำที่ใช้บ่อย**
| เรื่อง | ตัวอย่าง | แปลว่า |
|---|---|---|
| ระยะห่าง | `p-4` `px-6` `mt-8` `gap-4` | เว้นขอบด้านใน / เว้นด้านนอก / ช่องว่างระหว่างชิ้น (1 หน่วย = 4px) |
| ขนาด | `w-full` `max-w-6xl` `h-64` | กว้างเต็ม / กว้างไม่เกิน / สูง |
| ตัวอักษร | `text-sm` `text-3xl` `font-bold` | ตัวเล็ก / ตัวใหญ่ / ตัวหนา |
| สี | `text-white` `bg-brand` `border-gray-200` | สีตัวอักษร / สีพื้น / สีขอบ |
| จัดวาง | `flex` `items-center` `justify-between` `grid grid-cols-3` | เรียงแนวนอน / จัดกลาง / ดันไปสองข้าง / แบ่ง 3 คอลัมน์ |
| ตกแต่ง | `rounded-xl` `shadow-md` `hover:opacity-80` | มุมโค้ง / เงา / จางลงตอนเอาเมาส์ชี้ |

![ระยะห่างของ Tailwind: padding margin และ gap หน่วยละ 4 พิกเซล](/img/12-spacing-scale.svg)
*padding เว้นด้านใน margin เว้นด้านนอก gap เว้นระหว่างชิ้น ตัวเลขละ 4px*

### CSS พอใช้: กล่องวางตรงไหน ซ้อนกันยังไง

ตารางข้างบนคือการแต่ง "หน้าตา" ของกล่อง ส่วนข้อ 5 จะมีคำอีกกลุ่มที่บอก **ตำแหน่ง** ของกล่อง เช่น เมนูที่ติดขอบบน หรือปุ่มที่ลอยอยู่มุมจอ คำกลุ่มนี้เป็น CSS ที่ Tailwind แค่ตั้งชื่อสั้นให้ ถ้ารู้ว่าข้างหลังคือ CSS อะไร เวลาหน้าเพี้ยนจะรู้ว่าต้องค้นคำไหน

**ทุกอย่างบนหน้าเว็บคือกล่อง** และกล่องมี 2 นิสัยหลัก (`display`)

| คำ Tailwind | CSS | กล่องทำตัวยังไง | ใช้ที่ไหนในบทนี้ |
|---|---|---|---|
| `block` | `display: block` | กินเต็มบรรทัด ชิ้นถัดไปขึ้นบรรทัดใหม่ (ค่าตั้งต้นของ `<div>` `<p>` `<li>`) | ลิงก์ในเมนูมือถือ ให้กดได้ทั้งแถว |
| (ไม่ต้องใส่) | `display: inline` | ไหลไปกับตัวหนังสือ **ใส่ `mt-` `mb-` ไม่มีผล** (ค่าตั้งต้นของ `<a>` `<span>`) | |
| `inline-block` | `display: inline-block` | อยู่ในบรรทัดเหมือนตัวหนังสือ แต่ใส่ `mt-8` `py-3` ได้เหมือนกล่อง | ปุ่มใน hero ที่เป็น `<a>` |
| `hidden` | `display: none` | หายไปเลย ไม่กินที่ | ซ่อนเมนูบนมือถือ |
| `flex` / `grid` | `display: flex` / `grid` | ตัวเองเป็นกล่องปกติ แต่**จัดลูกข้างใน**ให้เรียงแถวหรือเป็นตาราง | เมนู, การ์ด, footer |

**ตำแหน่ง (`position`)** ปกติกล่องเรียงต่อกันจากบนลงล่าง คำเหล่านี้ดึงกล่องออกจากแถว

| คำ Tailwind | กล่องวางตามอะไร | ใช้ที่ไหนในบทนี้ | ลืมใส่แล้วเกิดอะไร |
|---|---|---|---|
| (ไม่ต้องใส่) `static` | เรียงตามลำดับในโค้ด | กล่องส่วนใหญ่ | |
| `relative` | อยู่ที่เดิม แต่กลายเป็น **"หมุด"** ให้ลูกที่เป็น `absolute` เกาะ | กรอบ hero | ชั้นมืดของ hero ไปคลุมทั้งหน้าจอ |
| `absolute` | เกาะกล่องแม่ที่ใกล้ที่สุดซึ่งเป็น `relative` (ไม่มีเลย = เกาะทั้งหน้าจอ) | ชั้นมืดบนรูป hero | |
| `fixed` | เกาะ**จอ** เลื่อนหน้าแล้วอยู่ที่เดิม | ปุ่ม LINE | ปุ่มไปอยู่ท้ายหน้า ต้องเลื่อนลงไปหา |
| `sticky` | เรียงปกติ จนเลื่อนถึงขอบที่บอก (`top-0`) แล้วติดค้างตรงนั้น | เมนูบน | เมนูเลื่อนหายไปกับหน้า |

คำบอกระยะใช้คู่กับ 4 คำข้างบน: `top-0` ชิดขอบบน, `bottom-5 right-5` ห่างขอบล่างและขวา 20px, `inset-0` ชิดทั้ง 4 ด้าน (คลุมเต็มกล่องแม่)

**ใครอยู่ข้างบน:** กล่องที่มี `relative` `absolute` `fixed` `sticky` จะถูกวาด**ทับ**กล่องปกติเสมอ ถ้าเป็นแบบนั้นทั้งคู่ ตัวที่อยู่หลังในโค้ดทับตัวก่อน และ `z-40` `z-50` ใช้บอกลำดับเอง เลขมากอยู่บน (ปุ่ม LINE `z-50` จึงลอยทับเมนู `z-40`)

**อีก 3 คำที่ใช้กับรูปและกล่อง**

| คำ Tailwind | ทำอะไร | ลืมใส่แล้วเกิดอะไร |
|---|---|---|
| `overflow-hidden` | ตัดส่วนที่ล้นออกนอกกล่อง | การ์ดมุมโค้ง แต่รูปข้างในยังเป็นมุมเหลี่ยมโผล่ออกมา |
| `object-cover` | รูปเต็มกรอบโดยไม่ยืด ส่วนที่เกินถูกตัด | รูปถูกบีบหรือยืดให้พอดีกรอบ คนดูอ้วนผิดรูป |
| `aspect-[4/3]` | ความสูงคิดจากความกว้าง (กว้าง 4 สูง 3) | การ์ดสูงไม่เท่ากันตามขนาดรูปต้นฉบับ |

**หน่วยความยาว:** `w-full` = `100%` ของกล่องแม่, `min-h-[60vh]` = สูงอย่างน้อย 60% ของ**ความสูงจอ** (`vh` = viewport height) และ `min-h-screen` = เต็มจอ ส่วนตัวเลขธรรมดาอย่าง `h-14` คือ 14 × 4 = 56px

> **ลองเห็นด้วยตา:** หลังทำ hero ในข้อ 5 เสร็จ เปิด DevTools → คลิกกล่องข้อความใน hero → แท็บ **Styles** หาบรรทัด `position: relative` แล้วกดติ๊กออก ตัวหนังสือจะจางลงทันที เพราะชั้นมืด (`absolute`) ทับมันแทน ติ๊กกลับ ตัวหนังสือก็กลับมาอยู่บน

## 3. สีและฟอนต์ของร้าน

งาน STARTER บังคับว่า **ใช้สี ฟอนต์ โลโก้ ตามสรุปร้านทั้งเว็บ และตั้งไว้ที่เดียว**

`src/index.css`
```css
@import url("https://fonts.googleapis.com/css2?family=Prompt:wght@400;600;700&display=swap");
@import "tailwindcss";

@theme {
  --color-brand: #6b3e26;        /* สีหลัก → ใช้ bg-brand, text-brand, border-brand */
  --color-brand-light: #f5ebe0;  /* สีรอง → bg-brand-light */
  --color-accent: #e9a03b;       /* สีเน้น → bg-accent */
  --font-sans: "Prompt", system-ui, sans-serif;   /* ฟอนต์หลักทั้งเว็บ */
}
```
ตอนนี้ใช้ `bg-brand`, `text-accent`, `bg-brand-light/50` (จางลงครึ่งหนึ่ง) ได้ทุกที่
ลูกค้าขอเปลี่ยนสี? แก้ **บรรทัดเดียว** ✅

**เช็คว่าใช้ได้จริง:** ใส่ `className="bg-brand text-white"` ให้ `<h1>` สักอัน แล้วเปิด DevTools (`F12`) → คลิกขวาที่ตัวหนังสือ → **Inspect** → แท็บ **Computed** พิมพ์ค้นว่า `font-family` ต้องเห็น `Prompt` อยู่ตัวแรก และ `background-color` เป็น `rgb(107, 62, 38)` (คือ `#6b3e26`) ถ้าฟอนต์ยังเป็นตัวเดิม ให้ดู 2 จุด:
- **ลำดับบรรทัด:** `@import url(...)` ของ Google Fonts ต้องอยู่ **บนสุด** ก่อน `@import "tailwindcss"` ถ้าสลับกัน `bun run build` จะเตือน `@import rules must precede all rules aside from @charset and @layer statements` แล้วทิ้งบรรทัดฟอนต์ไปเงียบๆ (ตอน `bun run dev` อาจไม่เห็นคำเตือนนี้เลย) เหตุผล: กฎของ CSS บังคับให้ `@import` อยู่ก่อนกฎอื่นทั้งหมด และ `@import "tailwindcss"` ถูกแปลงเป็นกฎ CSS จำนวนมาก บรรทัด import ที่ตามหลังจึงผิดกฎ
- **แท็บ Network:** กรองด้วยคำว่า `font` ต้องเห็นไฟล์จาก `fonts.gstatic.com` โหลดสำเร็จ (สถานะ 200)

![ตั้งสีร้านใน @theme ที่เดียว แล้วทุกคลาสสีทั้งเว็บเปลี่ยนตาม](/img/12-theme-colors.svg)
*สีอยู่ที่เดียวใน @theme คลาสอย่าง bg-brand ดึงไปใช้ทุกที่*

## 4. ทำให้พอดีทุกจอ: เริ่มจากมือถือ

Tailwind มี **จุดเปลี่ยน (breakpoint)** = ความกว้างจอที่คำนั้นเริ่มทำงาน

| คำนำหน้า | เริ่มที่ | อุปกรณ์ |
|---|---|---|
| (ไม่มี) | 0px | มือถือ (ทุกจอ) |
| `sm:` | 640px | มือถือแนวนอน |
| `md:` | 768px | แท็บเล็ต |
| `lg:` | 1024px | โน้ตบุ๊ค |
| `xl:` | 1280px | คอมจอใหญ่ |

**อ่านว่า "ตั้งแต่ ... ขึ้นไป"** ไม่ใช่ "เฉพาะ"

```tsx
<div className="grid grid-cols-1 md:grid-cols-2 xl:grid-cols-3 gap-6">
```
= มือถือ 1 คอลัมน์ → ตั้งแต่ 768px เป็น 2 คอลัมน์ → ตั้งแต่ 1280px เป็น 3 คอลัมน์


![จุดเปลี่ยน sm md lg xl และการ์ดที่เปลี่ยนจาก 1 เป็น 2 เป็น 3 คอลัมน์ตามความกว้างจอ](/img/12-breakpoints.svg)
*จอกว้างขึ้นถึงจุดเปลี่ยนไหน คำนำหน้านั้นก็เริ่มทำงาน*

> **กับดัก:** คิดว่า `md:` คือมือถือ ❌ คำที่ **ไม่มีคำนำหน้า** คือมือถือ ส่วน `md:` คือจอใหญ่กว่า

## 5. ลงมือ: ชิ้นส่วนที่งาน STARTER ต้องมี

### เมนูบน + ปุ่ม บนมือถือ
`src/components/navbar.tsx`
```tsx
import { useState } from "react";

const links = [
  { href: "/", label: "หน้าแรก" },
  { href: "/about", label: "เกี่ยวกับเรา" },
  { href: "/contact", label: "ติดต่อ" },
];

export default function Navbar({ shopName, logoUrl }: { shopName: string; logoUrl: string }) {
  const [open, setOpen] = useState(false);

  return (
    <header className="sticky top-0 z-40 bg-white shadow-sm">
      <nav className="mx-auto flex max-w-6xl items-center justify-between px-4 py-3">
        <a href="/" className="flex items-center gap-2 font-bold text-brand">
          <img src={logoUrl} alt={shopName} className="h-10 w-10 rounded-full" />
          {shopName}
        </a>

        {/* จอใหญ่: เมนูเรียงแนวนอน / มือถือ: ซ่อน */}
        <ul className="hidden gap-6 md:flex">
          {links.map((l) => (
            <li key={l.href}><a href={l.href} className="hover:text-brand">{l.label}</a></li>
          ))}
        </ul>

        {/* มือถือ: ปุ่ม hamburger / จอใหญ่: ซ่อน */}
        <button className="md:hidden text-2xl" onClick={() => setOpen(!open)} aria-label="เปิดเมนู">
          {open ? "✕" : "☰"}
        </button>
      </nav>

      {open && (
        <ul className="border-t border-gray-200 px-4 pb-4 md:hidden">
          {links.map((l) => (
            <li key={l.href}><a href={l.href} className="block py-2">{l.label}</a></li>
          ))}
        </ul>
      )}
    </header>
  );
}
```
(บทที่ 13 จะเปลี่ยน `<a>` เป็น `NavLink` เพื่อให้เมนูของหน้าที่อยู่เด่นขึ้น)

`sticky top-0` ทำให้เมนูติดขอบบนตอนเลื่อนหน้า และ `z-40` ให้มันลอยทับเนื้อหาที่เลื่อนผ่านข้างใต้ (อ่านเพิ่มที่ [CSS พอใช้](#css-พอใช้-กล่องวางตรงไหน-ซ้อนกันยังไง))

> **เคล็ดลับ:** ทำไมต้องใส่ `border-gray-200` คู่กับ `border-t`: ใน Tailwind 4 สีเส้นขอบตั้งต้นคือ `currentColor` (สีเดียวกับตัวหนังสือ) ไม่ใช่สีเทาอ่อนแบบ Tailwind 3 ถ้าใส่แค่ `border-t` จะได้เส้นสีเข้มเท่าตัวอักษร ตัวอย่างในเน็ตที่เขียนสำหรับรุ่น 3 จึงมักได้เส้นเข้มกว่าที่เห็นในภาพ

![Navbar บนมือถือแสดงปุ่ม ☰ ส่วนจอตั้งแต่ md ขึ้นไปแสดงลิงก์เรียงแนวนอน](/img/12-navbar-responsive.svg)
*hidden md:flex และ md:hidden ทำงานสลับกัน จอแคบเห็นปุ่ม ☰ จอกว้างเห็นลิงก์*

### ภาพใหญ่ด้านบนหน้าแรก
`src/components/hero.tsx` ข้อความและรูปรับเข้ามาทาง props (ตอนนี้ใส่ค่าเองใน `app.tsx` ท้ายข้อนี้ บทที่ 14 จะดึงจากฐานข้อมูล)
```tsx
export interface HeroContent {
  title: string;
  subtitle: string;
  imageUrl: string;
  ctaText: string;
}

export default function Hero({ hero }: { hero: HeroContent }) {
  return (
    <section
      className="relative flex min-h-[60vh] items-center justify-center bg-cover bg-center px-4 text-center text-white"
      style={{ backgroundImage: `url(${hero.imageUrl})` }}       // รูปมาจาก API ใช้ style แทน class
    >
      <div className="absolute inset-0 bg-black/50" />            {/* ชั้นมืดให้อ่านตัวหนังสือออก */}
      <div className="relative max-w-2xl">
        <h1 className="text-3xl font-bold md:text-5xl">{hero.title}</h1>
        <p className="mt-4 text-lg md:text-xl">{hero.subtitle}</p>
        <a href="/contact" className="mt-8 inline-block rounded-full bg-accent px-8 py-3 font-semibold text-brand hover:opacity-90">
          {hero.ctaText}
        </a>
      </div>
    </section>
  );
}
```
ทำไมมี `relative` สองที่: กรอบ `<section>` เป็นหมุดให้ชั้นมืด `absolute inset-0` คลุมแค่ในกรอบ (ไม่งั้นคลุมทั้งหน้า) ส่วน `<div>` ข้อความใส่ `relative` เพื่อให้ถูกวาดทับชั้นมืด (ไม่งั้นตัวหนังสือจมอยู่ใต้ชั้นมืด) ดู [CSS พอใช้](#css-พอใช้-กล่องวางตรงไหน-ซ้อนกันยังไง)

### การ์ดสินค้าแบบตาราง (grid)
![เปรียบเทียบ flex ที่เรียงในแนวเดียวกับ grid ที่แบ่งเป็นช่อง](/img/12-flex-grid.svg)
*flex เหมาะกับเรียงชิ้นในแถวเดียว grid เหมาะกับแบ่งเป็นตาราง*
ไม่ต้องเขียนการ์ดใหม่ ใช้ `ServiceCard` จากบทที่ 11 แล้ว **แต่งตัวการ์ดในไฟล์ของมันเอง** (การ์ดหน้าตาเหมือนกันทุกที่ที่ใช้) เขียนทับ `src/components/service-card.tsx` ทั้งไฟล์
```tsx
import type { Service } from "../types/service";

interface Props {
  service: Service;
}

export default function ServiceCard({ service }: Props) {
  return (
    <article className="overflow-hidden rounded-2xl bg-white shadow-md">
      <img src={service.imageUrl} alt={service.name} className="aspect-[4/3] w-full object-cover" />
      <div className="p-5">
        <h3 className="text-xl font-semibold">{service.name}</h3>
        <p className="mt-2 text-gray-600">{service.description}</p>
        {service.price !== null && <p className="mt-4 font-bold text-brand">{service.price.toLocaleString()} บาท</p>}
      </div>
    </article>
  );
}
```
ส่วน "ตาราง" เป็นหน้าที่ของคนที่วางการ์ดหลายใบ (`app.tsx` ด้านล่าง):
```tsx
<div className="mx-auto grid max-w-6xl grid-cols-1 gap-6 px-4 md:grid-cols-2 xl:grid-cols-3">
  {data?.map((s) => <ServiceCard key={s.id} service={s} />)}
</div>
```
แยกแบบนี้เพราะการ์ดรู้แค่ว่า "การ์ด 1 ใบหน้าตาเป็นยังไง" ส่วนจะเรียงกี่คอลัมน์เป็นเรื่องของหน้าที่ใช้มัน บทที่ 13 จะใช้การ์ดตัวเดียวกันนี้ในหน้าอื่นได้ทันที

### ปุ่ม LINE ลอยมุมขวาล่าง
`src/components/line-button.tsx`
```tsx
export default function LineButton({ lineUrl }: { lineUrl: string }) {
  return (
    <a
      href={lineUrl}
      target="_blank"
      rel="noopener noreferrer"
      className="fixed bottom-5 right-5 z-50 flex h-14 w-14 items-center justify-center rounded-full bg-[#06C755] text-white shadow-lg hover:scale-105"
      aria-label="แชท LINE"
    >
      LINE
    </a>
  );
}
```
 `bg-[#06C755]` = ใส่ค่าเองในวงเล็บเหลี่ยม ใช้กับค่าที่ไม่ได้ตั้งไว้ (นี่คือสีเขียวของ LINE)

`fixed bottom-5 right-5` = เกาะจอ ห่างขอบล่างและขวา 20px เลื่อนหน้าแล้วปุ่มยังอยู่ที่เดิม ส่วน `z-50` มากกว่าเมนู (`z-40`) ปุ่มจึงลอยทับเมนูได้ถ้าซ้อนกัน

### ประกอบทั้งหน้า: `src/app.tsx`
เขียนทับ `src/app.tsx` ของบทที่ 11 ข้อมูลร้านและภาพใหญ่ใส่เป็นค่าคงที่ไว้ก่อน (บทที่ 14 จะย้ายไปเก็บในฐานข้อมูล) ส่วนรายการสินค้ายังดึงจาก `/mock/services.json` เหมือนเดิม
```tsx
import Navbar from "./components/navbar";
import Hero, { type HeroContent } from "./components/hero";
import ServiceCard from "./components/service-card";
import Footer from "./components/footer";
import LineButton from "./components/line-button";
import { useFetch } from "./api/useFetch";
import type { Service } from "./types/service";

// ข้อมูลร้านชั่วคราว (รูปโลโก้: วางไฟล์ logo.png ไว้ใน public/ ถ้ายังไม่มีจะเห็นแค่ข้อความ alt)
const shop = {
  shopName: "Bit Café",
  logoUrl: "/logo.png",
  address: "123 ถ.สุขุมวิท กรุงเทพฯ",
  phone: "0812345678",
  openingHours: "ทุกวัน 08:00–18:00",
  lineUrl: "https://line.me/",
};

const hero: HeroContent = {
  title: "กาแฟดี ใกล้บ้านคุณ",
  subtitle: "คั่วสดทุกสัปดาห์ เสิร์ฟด้วยรอยยิ้ม",
  imageUrl: "https://picsum.photos/seed/cafe/1600/900",
  ctaText: "ติดต่อเรา",
};

export default function App() {
  const { data, error, loading } = useFetch<Service[]>("/mock/services.json");

  return (
    <div className="flex min-h-screen flex-col">
      <Navbar shopName={shop.shopName} logoUrl={shop.logoUrl} />
      <main className="flex-1">
        <Hero hero={hero} />
        <section className="py-12">
          <h2 className="mb-6 text-center text-2xl font-bold text-brand">เมนูแนะนำ</h2>
          {loading && <p className="text-center">กำลังโหลด... ⏳</p>}
          {error && <p className="text-center">โหลดข้อมูลไม่สำเร็จ: {error} 😢</p>}
          <div className="mx-auto grid max-w-6xl grid-cols-1 gap-6 px-4 md:grid-cols-2 xl:grid-cols-3">
            {data?.map((s) => <ServiceCard key={s.id} service={s} />)}
          </div>
        </section>

      <Footer address={shop.address} phone={shop.phone} openingHours={shop.openingHours} />
      <LineButton lineUrl={shop.lineUrl} />
    </div>
  );
}
```
**ควรเห็น** หลัง `bun run dev`: เมนูบนติดขอบบน, ภาพใหญ่มีชั้นมืดและข้อความ "กาแฟดี ใกล้บ้านคุณ", การ์ด 3 ใบ (ลาเต้ มอคค่า จัดเลี้ยงนอกสถานที่) ส่วนท้ายสีน้ำตาล และปุ่ม LINE สีเขียวมุมขวาล่าง สั่ง `bun run build` ต้องผ่านโดยไม่มี error

## 6. ลองทุกขนาดจอ

1. เปิด DevTools (`F12` / `⌘ + ⌥ + I`)
2. กดไอคอนรูปมือถือ (**Toggle device toolbar**, `⌘ + ⇧ + M`)
3. เลือก **Responsive** แล้วพิมพ์ความกว้าง **375**, **768**, **1280** ทีละค่า

**ต้องผ่านทุกข้อ**
- [ ] ไม่มีอะไรล้นจนเลื่อนซ้ายขวาได้
- [ ] ตัวหนังสือไม่ล้นกล่อง รูปไม่ยืดเบี้ยว
- [ ] บนมือถือเห็นปุ่ม ☰ และกดเปิดเมนูได้
- [ ] ปุ่มใหญ่พอกดด้วยนิ้ว (สูงประมาณ 44px ขึ้นไป)

> **เคล็ดลับ:** หาว่าชิ้นไหนทำให้ล้น: วางคำสั่งนี้ใน Console
> ```js
> [...document.querySelectorAll("*")].filter((el) => el.scrollWidth > document.documentElement.clientWidth)
> ```

## 7. ปัญหาที่เจอบ่อย

| อาการ | สาเหตุ | วิธีแก้ |
|---|---|---|
| ใส่คำแล้วไม่มีผล | ต่อคำเองแบบ `bg-${color}-500` | Tailwind หาคำจาก **ข้อความเต็มๆ** ในโค้ด ต้องเขียนเต็ม เช่น `bg-red-500` |
| มือถือเลื่อนซ้ายขวาได้ | ใส่ความกว้างตายตัว `w-[500px]` | ใช้ `w-full max-w-...` |
| ทั้งเว็บไม่มีการตกแต่ง | ลืม `@import "tailwindcss"` หรือลืมใส่ใน `vite.config.ts` | ตรวจข้อ 2 |
| `bg-brand` ไม่ทำงาน | ชื่อใน `@theme` ไม่ได้ขึ้นต้นด้วย `--color-` | ต้องเป็น `--color-ชื่อ` |
| `className` ยาวจนอ่านยาก | ใส่ทุกอย่างไว้ที่เดียว | แยกเป็นชิ้นส่วนย่อย เช่น `<Button>` |
| ฟอนต์ไม่เปลี่ยน และ `bun run build` เตือน `@import rules must precede all rules...` | `@import url(...)` ของฟอนต์อยู่ใต้ `@import "tailwindcss"` | ย้ายบรรทัดฟอนต์ขึ้นไปบนสุด (ข้อ 3) |
| ชั้นมืดของ hero คลุมทั้งหน้าจอ | กรอบ `<section>` ไม่มี `relative` กล่อง `absolute` เลยเกาะทั้งหน้าแทน | ใส่ `relative` ที่กรอบ (ข้อ 1 "CSS พอใช้") |
| ตัวหนังสือใน hero จางเหมือนโดนบัง | `<div>` ข้อความไม่มี `relative` ชั้นมืดจึงถูกวาดทับ | ใส่ `relative` ที่กล่องข้อความ |
| รูปในการ์ดมุมเหลี่ยมโผล่เกินมุมโค้ง | การ์ดไม่มี `overflow-hidden` | ใส่ `overflow-hidden` ที่ `<article>` |
| เส้นขอบเข้มเท่าตัวหนังสือ | Tailwind 4 ใช้ `currentColor` เป็นสีขอบตั้งต้น | ใส่สีเอง เช่น `border border-gray-200` |
| `Cannot find name 'hero'` / `Cannot find module './components/hero'` | ลอกแค่ส่วน `<section>` ไปวางโดยไม่ได้สร้างไฟล์ `hero.tsx` | สร้างไฟล์ตามข้อ 5 ทั้งไฟล์ แล้ว import ใน `app.tsx` |

> **หาคลาสเองเป็น ไม่ต้องจำ:** เปิด [tailwindcss.com/docs](https://tailwindcss.com/docs) กด `Ctrl + K` (Mac: `⌘ + K`) แล้วพิมพ์ **ชื่อ property ของ CSS** ที่อยากได้ เช่น `position`, `object-fit`, `gap` จะเจอหน้าที่บอกว่าคลาสไหนตรงกับ CSS อะไร ในโค้ด ให้เอาเมาส์ชี้ชื่อคลาส (ต้องมีส่วนเสริม Tailwind CSS IntelliSense) จะเห็น CSS จริงที่คลาสนั้นสร้าง และในเบราว์เซอร์ DevTools แท็บ **Styles** จะบอกว่าคลาสไหนทำงานหรือถูกขีดฆ่าทับ

## เช็คความเข้าใจ

<details>
<summary>1. `hidden md:flex` แปลว่าอะไร?</summary>

จอแคบกว่า 768px (มือถือ) ซ่อนไว้ / ตั้งแต่ 768px ขึ้นไปแสดงแบบเรียงแนวนอน

</details>

<details>
<summary>2. ทำไมตั้งสีร้านไว้ใน `@theme` ดีกว่าใส่ `bg-[#6b3e26]` ทุกที่?</summary>

ค่าอยู่ที่เดียว ลูกค้าขอเปลี่ยนสีแก้บรรทัดเดียว และชื่อ `bg-brand` อ่านแล้วรู้เลยว่าเป็นสีร้าน

</details>

<details>
<summary>3. ทำไมตารางหน้าจัดการร้านต้องห่อด้วย `overflow-x-auto`?</summary>

ตารางที่มีหลายคอลัมน์กว้างกว่าจอมือถือ ถ้าไม่ห่อ ทั้งหน้าจะเลื่อนซ้ายขวาได้ ห่อแล้วเลื่อนเฉพาะในกรอบตาราง

</details>

<details>
<summary>4. ถ้าเปลี่ยนเมนูบนจาก `sticky` เป็น `fixed` จะเกิดอะไร?</summary>

เมนูยังติดขอบบนเหมือนเดิม แต่ `fixed` ไม่กินที่ในแถวแล้ว กล่องถัดไป (hero) จึงเลื่อนขึ้นไปอยู่ใต้เมนู ส่วนบนของ hero ถูกเมนูบังตั้งแต่เปิดหน้า `sticky` ไม่มีปัญหานี้เพราะยังกินที่ของตัวเองอยู่

</details>
