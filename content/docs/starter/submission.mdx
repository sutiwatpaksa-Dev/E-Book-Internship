> 📄 **ใช้กับทุกโจทย์** เกณฑ์และสิ่งที่ต้องส่งเหมือนกันทุกโจทย์ ของเฉพาะโจทย์ STARTER มีป้าย "STARTER:" · ต้นฉบับ: [Requirement ของรุ่นตัวเอง หัวข้อสิ่งที่ต้องส่ง](/api/files/requirement.pdf?sec=submission)

> **⚡ สรุป 30 วินาที**
> - ส่งงานใน Git ที่เดียว (มีทั้ง `client` และ `server`) พร้อม README, ผังตาราง, ไฟล์ทดสอบ API, สรุปธุรกิจ (brief) + ภาพร่างหน้าเว็บ และนำเสนอสด 15 นาที
> - ผ่าน = **ได้ 70 คะแนนขึ้นไป** และ **ไม่พลาด 3 ข้อที่ตกทันที**
> - งานเสริม (bonus) ทำได้ **เมื่องานหลักครบแล้วเท่านั้น**

---

## 📦 สิ่งที่ต้องส่ง

- [ ] งานใน Git 1 ที่ (มีทั้ง `client` และ `server`)
- [ ] README บอกวิธี: ติดตั้ง, ตั้งค่าไฟล์ `.env`, สร้างตาราง + ข้อมูลตั้งต้น, เปิดเว็บ, บัญชี admin สำหรับทดสอบ
- [ ] ผังตาราง (ER Diagram)
- [ ] ไฟล์ที่รวมการเรียก API ทุกตัวไว้ (จาก Postman หรือไฟล์ `.http`)
- [ ] สรุปธุรกิจ (brief) + ภาพร่างหน้าเว็บ (wireframe)
- [ ] นำเสนอสด 15 นาที: เล่าเรื่องธุรกิจ → โชว์หน้าเว็บ → แก้ข้อมูลในหน้าจัดการให้ดูว่าหน้าเว็บเปลี่ยนจริง → ตอบคำถามเรื่องโค้ด

> 💡 ก่อนส่ง ให้เพื่อนเอางานไปรันตาม README บนเครื่องเพื่อนเอง ถ้าเพื่อนต้องหันมาถามน้องแม้แต่ข้อเดียว แปลว่า README ยังไม่ครบ

## เกณฑ์ประเมิน (100 คะแนน)

| หัวข้อ | คะแนน | ดูอะไร |
|---|---|---|
| ฐานข้อมูล | 15 | ออกแบบตารางมีเหตุผล, การเชื่อมตารางและค่าห้ามซ้ำถูก, สร้างตารางด้วย migration ได้จริง |
| API | 25 | ครบตามรายการ, ตรวจข้อมูลด้วย Zod ทุกตัว, ตัวเลขบอกผลถูก, ระบบ login ปลอดภัย |
| หน้าเว็บลูกค้า | 20 | ครบทุกหน้าตามโจทย์ (STARTER: 3 หน้า), ข้อมูลมาจาก API จริง, ใช้ได้ทุกจอ, มีข้อความตอนโหลด/พัง |
| หน้าจัดการ (หลังบ้าน) | 20 | เพิ่ม/ดู/แก้/ลบ ครบ, แก้แล้วหน้าเว็บเปลี่ยนจริง, เจ้าของธุรกิจใช้เป็น |
| Google + ความปลอดภัย | 10 | ชื่อหน้า/คำอธิบาย, การ์ดตอนแชร์, จำกัดการส่งฟอร์ม, cookie ปลอดภัย |
| โค้ด + README + นำเสนอ | 10 | อ่านง่าย, ไม่ใช้ `any` มั่ว, ตอบคำถามเรื่องโค้ดตัวเองได้ |

![เกณฑ์ประเมิน 100 คะแนน หกหัวข้อ ผ่านเมื่อได้ 70 ขึ้นไปและไม่พลาดสามข้อที่ตกทันที](/img/starter-grading.svg)
*สัดส่วนคะแนนแต่ละหัวข้อ และเงื่อนไขผ่าน*

> ⚠️ **ผ่าน = 70 คะแนนขึ้นไป** และต้องไม่มีข้อต่อไปนี้ (มีข้อเดียว = **ไม่ผ่านทันที**)
> - ❌ รหัสผ่านไม่ได้ hash ด้วย bcrypt/argon2 (เช่น เก็บเป็นตัวจริง หรือเข้ารหัสแบบที่ถอดกลับได้)
> - ❌ เรียก API ของหน้าจัดการ (หลังบ้าน) ได้ โดยไม่ต้อง login
> - ❌ ทำตาม README แล้วเปิดเว็บไม่ขึ้น

## 🎁 งานเสริม (Bonus)

ทำได้เมื่องานหลักครบแล้วเท่านั้น **งานหลักยังไม่ครบแต่ไปทำงานเสริม = ไม่ได้คะแนนเพิ่ม**

- 🖼️ ปุ่มอัปโหลดรูปจริง แทนการใส่ลิงก์รูป
- 🔔 แจ้งเตือนเข้า LINE หรืออีเมล เมื่อมีลูกค้าส่งข้อมูลใหม่เข้ามา (STARTER: ข้อความจากฟอร์มติดต่อ) (LINE Notify ปิดบริการแล้ว ต้องใช้ LINE Messaging API ผ่าน LINE Official Account และเก็บ token ไว้ใน `.env` ฝั่ง server เท่านั้น)
- ⚡ ทำให้ LINE/Facebook เห็นเนื้อหาครบตอนแชร์ (prerender: [บทที่ 13 ข้อ 7](/13-router-seo))
- 🐳 เปิดทั้งระบบ (ฐานข้อมูล + server + หน้าเว็บ) ได้ด้วยคำสั่งเดียว ([บทที่ 20](/20-deploy-vps))
- 🚀 ขึ้นเว็บจริงบนอินเทอร์เน็ต พร้อมชื่อเว็บของตัวเอง ([ด่าน 7: บทที่ 17–23](/17-network))
- 🧪 เขียนโค้ดทดสอบอัตโนมัติ อย่างน้อยให้ทดสอบการตรวจข้อมูลและด่านตรวจ login ([ตัวอย่างในบทที่ 21 ข้อ 2](/21-cicd))
