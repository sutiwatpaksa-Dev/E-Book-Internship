## v2.0.12 · 24 ต.ค. 2569

- **การ์ดทั้ง 17 ใบตรงกับ Requirement งาน STARTER แล้ว:** โค้ดตัวอย่างทุกใบตอบรูปแบบเดียวกับ Requirement (`{ success, data }` / `{ success: false, error: { code, message, details } }`), ใช้คำสั่ง Bun (`bun add`, `bunx`) และการ์ดยิงทดสอบสอนทำ Postman collection ที่ต้องส่ง
- **หัวการ์ดบอกว่า "ใช้ในงาน STARTER วันที่เท่าไร"** และขั้น Coding แบ่งช่วงตามวันของงาน: เตรียมเครื่อง → DB → API → Login → Frontend → หลังบ้าน (เดิม DB → Backend → API → Frontend ซึ่งทำให้บางการ์ดใช้ Hono ก่อนได้เรียน)
- **มีส่วน "ตั้งค่าครั้งแรก"** ในการ์ดที่ต้องติดตั้ง (pgAdmin, Drizzle, Hono, Vite, proxy, Tailwind, React Router) และ "ควรเห็น" บอกผลที่ต้องได้ทุกขั้น ทำตามตั้งแต่การ์ดแรกถึงการ์ดสุดท้ายได้ระบบห้องสมุดที่รันได้จริง (ทดลองทำตามครบทุกขั้นแล้ว)
- ทุกการ์ดมีส่วน **"นึกภาพ"** เปรียบเทียบกับเรื่องใกล้ตัว และศัพท์ที่เจอครั้งแรกกดไปดูความหมายในอภิธานศัพท์ได้
