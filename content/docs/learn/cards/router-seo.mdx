## ความหมาย

**[Router](/glossary#router)** ทำให้เว็บ React มีหลายหน้าตามที่อยู่ (`/books`, `/books/7`) โดยไม่ต้องโหลดหน้าใหม่จาก server ทุกครั้ง กดย้อนกลับได้ และส่งลิงก์ให้คนอื่นแล้วเปิดเจอหน้าเดียวกัน

**[SEO](/glossary#seo)** คือการบอก Google และแอปแชตว่าหน้านี้คืออะไร ผ่าน `<title>`, `<meta name="description">` และแท็ก [`og:`](/glossary#og) ที่ LINE กับ Facebook ใช้ทำการ์ดตอนแชร์ลิงก์

**นึกภาพ:** ห้างสรรพสินค้า router คือป้ายบอกชั้นและเลขห้อง บอกเลขห้องให้เพื่อนแล้วเพื่อนเดินมาถูก ส่วน SEO คือป้ายหน้าร้านที่บอกคนเดินผ่าน (Google) ว่าร้านนี้ขายอะไร

```text
กดลิงก์ไป /books/7 ในเว็บ
   │ React Router เปลี่ยน URL เอง
   │ ไม่ขอหน้าใหม่จาก server
   ▼
วาดหน้า BookPage ของเล่ม 7
   │
   ▼
ปุ่มย้อนกลับของ browser
กลับไป /books ได้ตามปกติ
```

จุดที่ไม่ตรง: ป้ายในห้างติดอยู่กับตึก แต่ router เป็นโค้ดใน browser ถ้ามีคนเปิด `/books/7` ตรงๆ (กดรีเฟรช หรือเปิดจากลิงก์ที่เพื่อนส่ง) คำขอวิ่งไปถึง server ก่อน server ต้องส่งหน้าเว็บหลักกลับไปให้ router ทำงาน ไม่งั้นได้ 404 (ทำในการ์ด [Build](/learn/cards/production-build))

## ที่มา

เว็บ React แบบ Vite มีไฟล์ HTML ไฟล์เดียว ถ้าสลับหน้าด้วย state ที่อยู่บนแถบ browser ไม่เปลี่ยน ลูกค้าส่งลิงก์หน้า "ติดต่อ" ให้เพื่อนไม่ได้ กดย้อนกลับแล้วหลุดออกจากเว็บ Router เอาที่อยู่มาเป็นตัวตัดสินว่าโชว์หน้าไหน ส่วนชื่อหน้า ถ้าไม่ตั้ง ทุกหน้าจะชื่อเดียวกับที่เครื่องมือสร้างโปรเจกต์ใส่ไว้ แชร์ลง LINE แล้วการ์ดขึ้นคำว่า "client"

## การใช้งาน

### ตั้งค่าครั้งแรก

```bash
cd client
bun add react-router
```

### 1. ห่อทั้งแอปครั้งเดียว

แก้ `src/main.tsx` เพิ่ม `BrowserRouter` ห่อ `<App />`

```tsx
import { StrictMode } from "react";
import { createRoot } from "react-dom/client";
import { BrowserRouter } from "react-router";
import "./index.css";
import App from "./App.tsx";

createRoot(document.getElementById("root")!).render(
  <StrictMode>
    <BrowserRouter>
      <App />
    </BrowserRouter>
  </StrictMode>,
);
```

### 2. ที่อยู่ → หน้า

แก้ `src/App.tsx` **ทั้งไฟล์** เดิม App แสดง `BooksPage` ตรงๆ ตอนนี้ App มีหน้าที่เดียว คือจับคู่ที่อยู่กับหน้า

```tsx
// src/App.tsx
import { Route, Routes } from "react-router";
import { PublicLayout } from "./components/public-layout";
import { BookPage } from "./pages/book-page";
import { BooksPage } from "./pages/books-page";
import { HomePage } from "./pages/home-page";
import { NotFoundPage } from "./pages/not-found-page";

export default function App() {
  return (
    <Routes>
      <Route element={<PublicLayout />}>            {/* เมนูบน + ส่วนท้าย ทุกหน้าใช้ร่วม */}
        <Route path="/" element={<HomePage />} />
        <Route path="/books" element={<BooksPage />} />
        <Route path="/books/:id" element={<BookPage />} />
        <Route path="*" element={<NotFoundPage />} />   {/* ไม่ตรงข้างบนเลย = 404 */}
      </Route>
    </Routes>
  );
}
```

`BooksPage` คือไฟล์เดิมจากการ์ด [ดึงข้อมูล](/learn/cards/data-fetching) ย้ายมาอยู่ที่ `/books` ส่วน `PublicLayout` กับ `BookPage` เขียนในข้อ 3–4 ข้างล่าง และอีก 2 หน้าสั้นๆ:

```tsx
// src/pages/home-page.tsx
import { Link } from "react-router";

export function HomePage() {
  return (
    <>
      <title>ห้องสมุดบิต</title>
      <meta name="description" content="ยืมหนังสือออนไลน์ เช็กได้ว่าเล่มไหนว่าง" />
      <h1 className="text-2xl font-bold">ห้องสมุดบิต</h1>
      <Link to="/books">ดูหนังสือทั้งหมด</Link>
    </>
  );
}
```

```tsx
// src/pages/not-found-page.tsx
export function NotFoundPage() {
  return (
    <>
      <title>ไม่พบหน้านี้ | ห้องสมุดบิต</title>
      <h1 className="text-2xl font-bold">ไม่พบหน้านี้</h1>
    </>
  );
}
```

`<Link>` ใช้แทน `<a href>` เปลี่ยนหน้าโดยไม่โหลดใหม่จาก server ถ้าใช้ `<a href>` ทั้งแอปจะโหลดใหม่ state ที่มีอยู่หายหมด

ฟอร์ม `NewBookForm` จากการ์ด [ฟอร์ม](/learn/cards/react-forms) ไม่อยู่ในหน้าบ้านแล้ว เพราะคนทั่วไปไม่ควรเพิ่มหนังสือเองได้ การเพิ่มหนังสือย้ายไปหลังบ้านในการ์ด [หน้าจัดการข้อมูล](/learn/cards/crud-ui) (ไฟล์เก็บไว้ดูเป็นแบบได้) ส่วนฟอร์มที่หน้าบ้านต้องมีในโจทย์ STARTER คือฟอร์มติดต่อ (โจทย์อื่นดูหัวข้อหน้าบ้านใน Requirement)

### 3. โครงหน้าร่วม

```tsx
// src/components/public-layout.tsx
import { NavLink, Outlet } from "react-router";

export function PublicLayout() {
  const link = ({ isActive }: { isActive: boolean }) => (isActive ? "font-bold text-brand" : "text-gray-600");
  return (
    <div className="mx-auto max-w-5xl px-4">
      <nav className="flex gap-4 py-4">
        <NavLink to="/" end className={link}>หน้าแรก</NavLink>
        <NavLink to="/books" className={link}>หนังสือ</NavLink>
      </nav>
      <main>
        <Outlet />     {/* หน้าลูกมาแสดงตรงนี้ */}
      </main>
    </div>
  );
}
```

`<NavLink>` ใช้แทน `<a href>` เปลี่ยนหน้าได้โดยไม่โหลดใหม่ และรู้ว่าเมนูไหนคือหน้าที่เปิดอยู่ (`isActive`)

### 4. หน้าลูกอ่าน `:id` และตั้งชื่อหน้า

React 19 ให้เขียน `<title>` กับ `<meta>` ในชิ้นส่วนไหนก็ได้ แล้วย้ายไปไว้ส่วนหัวของหน้าให้เอง

```tsx
// src/pages/book-page.tsx
import { useEffect, useState } from "react";
import { useParams } from "react-router";
import { booksApi } from "../api/books.api";
import type { Book } from "../types/book";

export function BookPage() {
  const { id } = useParams();                       // /books/2 → "2"
  const [book, setBook] = useState<Book | null>(null);
  const [error, setError] = useState("");

  useEffect(() => {
    booksApi.get(Number(id)).then(setBook).catch((e: Error) => setError(e.message));
  }, [id]);                                         // เปลี่ยนเล่ม = ดึงใหม่

  if (error) return <p role="alert">{error}</p>;
  if (!book) return <p>กำลังโหลด...</p>;
  return (
    <>
      <title>{`${book.title} | ห้องสมุดบิต`}</title>
      <meta name="description" content={`รายละเอียดหนังสือ ${book.title}`} />
      <h1 className="text-2xl font-bold">{book.title}</h1>
    </>
  );
}
```

**ควรเห็น:** (เปิด `bun run dev` ทั้ง `server/` และ `client/`) เปิด `http://localhost:5173/` เห็นหัวข้อ "ห้องสมุดบิต" กดเมนู "หนังสือ" ได้รายการจากฐานข้อมูล และที่อยู่เปลี่ยนเป็น `/books` โดยหน้าไม่กะพริบ เปิด `/books/2` ชื่อแท็บเป็น `ฮอบบิท | ห้องสมุดบิต` เปิด `/books/99` ได้ "ไม่พบหนังสือ" (ข้อความจาก API) และเปิด `/อะไรก็ได้` ได้ "ไม่พบหน้านี้"

## ทริคที่แนะนำ

1. **ตัวกรองเก็บใน URL ไม่ใช่ใน state:** `/books?category=novel` ด้วย `useSearchParams` ส่งลิงก์ต่อแล้วเพื่อนเห็นหน้าที่กรองแล้วเหมือนกัน กดย้อนกลับก็กลับไปตัวกรองก่อนหน้า
2. **ต้องมีหน้า 404 (`path="*"`)** ไม่งั้นพิมพ์ที่อยู่ผิดแล้วได้หน้าว่าง ไม่มีทางกลับ
3. **`og:image` ต้องเป็นที่อยู่เต็ม `https://...`** LINE กับ Facebook ไม่รู้ว่า `/og.jpg` หมายถึงเว็บไหน

## ปรับไปใช้จริง

**ในโจทย์ฝึกงาน** (ตัวอย่างจาก STARTER)**:** วันที่ 6 ทำ layout (Navbar + Footer) ด้วยโครงหน้าร่วมแบบข้อ 3 และวันที่ 9 ตรวจ SEO: ทุกหน้ามี title/description, มี OG tags, รูปมี `alt`, `<h1>` หน้าละ 1 ตัว, มี `robots.txt` และ `sitemap.xml` (ไฟล์ธรรมดาในโฟลเดอร์ `client/public/`) และ **README ต้องอธิบายข้อจำกัด SEO ของเว็บแบบ [SPA](/glossary#spa)** (ดูย่อหน้า "ข้อจำกัดของเว็บ Vite + React Router" ด้านล่าง)

**เว็บคู่มือนี้:** ใช้ Next.js ที่มี router ในตัว: แต่ละโฟลเดอร์ใน `src/app/` คือที่อยู่หนึ่งหน้า (`src/app/(app)/today/page.tsx` คือ `/today`) แนวคิดเดียวกับ React Router คือ "ที่อยู่ → หน้า" + "โครงหน้าร่วม" (`layout.tsx` ทำหน้าที่เดียวกับ `PublicLayout` + `Outlet`) ส่วนชื่อหน้าตั้งด้วย `metadata` เช่น หน้าวันนี้ตั้ง `title: "วันนี้"`

ข้อจำกัดของเว็บ Vite + React Router ที่ต้องอธิบายลูกค้าได้: server ส่ง HTML ว่างมาก่อน แล้ว JavaScript ค่อยวาดเนื้อหา Google รอวาดได้ แต่แอปแชตบางตัวไม่รอ การ์ดแชร์ลิงก์จึงอาจไม่ขึ้นตามชื่อหน้าที่ตั้งในชิ้นส่วน

ลองคิด: หน้าไหนในโจทย์ฝึกงาน ที่ "ต้อง" ขึ้นใน Google และหน้าไหนที่ไม่ควรขึ้นเลย

## ตัวเลือกอื่นที่คล้ายกัน

| วิธี | ที่อยู่ → หน้า กำหนดที่ | ระดับ |
|---|---|---|
| **React Router (ทีมใช้กับ Vite)** | `<Route path>` ในโค้ด | ใช้กับโจทย์ฝึกงาน |
| Next.js | โฟลเดอร์ใน `app/` และ HTML สร้างฝั่ง server ได้ | ควรรู้จัก เว็บคู่มือนี้ใช้ |
| TanStack Router | ประกาศ route แบบ type ตรวจได้ทุกพารามิเตอร์ | รู้ว่ามี |
| สลับหน้าด้วย state | ไม่มี ที่อยู่ไม่เปลี่ยน | ใช้แค่ป๊อปอัปหรือแท็บย่อยในหน้า |

## ลองเอง

**โจทย์:** ทำ 3 หน้า: รายการหนังสือที่กรองตามหมวดได้ (ตัวกรองอยู่ใน URL), หน้ารายละเอียดหนังสือ `/books/:id` ที่ชื่อแท็บเป็นชื่อหนังสือ และหน้า 404 ที่มีปุ่มกลับหน้าแรก ทุกหน้าใช้เมนูบนชุดเดียวกัน และเมนูของหน้าที่เปิดอยู่ต้องเด่นกว่าเมนูอื่น
