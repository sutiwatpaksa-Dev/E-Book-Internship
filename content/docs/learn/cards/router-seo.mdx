## ความหมาย

**Router** ทำให้เว็บ React มีหลายหน้าตามที่อยู่ (`/books`, `/books/7`) โดยไม่ต้องโหลดหน้าใหม่จาก server ทุกครั้ง กดย้อนกลับได้ และส่งลิงก์ให้คนอื่นแล้วเปิดเจอหน้าเดียวกัน

**SEO** คือการบอก Google และแอปแชตว่าหน้านี้คืออะไร ผ่าน `<title>`, `<meta name="description">` และแท็ก `og:` ที่ LINE กับ Facebook ใช้ทำการ์ดตอนแชร์ลิงก์

## ที่มา

เว็บ React แบบ Vite มีไฟล์ HTML ไฟล์เดียว ถ้าสลับหน้าด้วย state ที่อยู่บนแถบ browser ไม่เปลี่ยน ลูกค้าส่งลิงก์หน้า "ติดต่อ" ให้เพื่อนไม่ได้ กดย้อนกลับแล้วหลุดออกจากเว็บ Router เอาที่อยู่มาเป็นตัวตัดสินว่าโชว์หน้าไหน ส่วนชื่อหน้า ถ้าไม่ตั้ง ทุกหน้าจะชื่อเดียวกับที่เครื่องมือสร้างโปรเจกต์ใส่ไว้ แชร์ลง LINE แล้วการ์ดขึ้นคำว่า "client"

## การใช้งาน

```tsx
// src/main.tsx · ห่อทั้งแอปครั้งเดียว
import { BrowserRouter } from "react-router";
createRoot(document.getElementById("root")!).render(
  <BrowserRouter>
    <App />
  </BrowserRouter>,
);
```

```tsx
// src/app.tsx · ที่อยู่ → หน้า
import { Route, Routes } from "react-router";

export default function App() {
  return (
    <Routes>
      <Route element={<PublicLayout />}>            {/* เมนูบน + ส่วนท้าย ทุกหน้าใช้ร่วม */}
        <Route path="/" element={<HomePage />} />
        <Route path="/books/:id" element={<BookPage />} />
        <Route path="*" element={<NotFoundPage />} />
      </Route>
    </Routes>
  );
}
```

ใน `PublicLayout` วาง `<Outlet />` ไว้ตรงที่ให้หน้าลูกมาแสดง เมนูใช้ `<NavLink to="/books">` แทน `<a href>` เปลี่ยนหน้าได้โดยไม่โหลดใหม่ และรู้ว่าเมนูไหนคือหน้าที่เปิดอยู่ ในหน้าลูกอ่าน `:id` ด้วย `useParams()`

ชื่อหน้าและคำอธิบาย: React 19 ให้เขียน `<title>` กับ `<meta>` ในชิ้นส่วนไหนก็ได้ แล้วย้ายไปไว้ส่วนหัวของหน้าให้เอง

```tsx
export function BookPage() {
  const { id } = useParams();
  // ...ดึงหนังสือเล่มนั้น
  return (
    <>
      <title>{`${book.title} | ห้องสมุดบิต`}</title>
      <meta name="description" content={book.summary} />
      <h1>{book.title}</h1>
    </>
  );
}
```

## ทริคที่แนะนำ

1. **ตัวกรองเก็บใน URL ไม่ใช่ใน state:** `/books?category=novel` ด้วย `useSearchParams` ส่งลิงก์ต่อแล้วเพื่อนเห็นหน้าที่กรองแล้วเหมือนกัน กดย้อนกลับก็กลับไปตัวกรองก่อนหน้า
2. **ต้องมีหน้า 404 (`path="*"`)** ไม่งั้นพิมพ์ที่อยู่ผิดแล้วได้หน้าว่าง ไม่มีทางกลับ
3. **`og:image` ต้องเป็นที่อยู่เต็ม `https://...`** LINE กับ Facebook ไม่รู้ว่า `/og.jpg` หมายถึงเว็บไหน

## ปรับไปใช้จริง

เว็บคู่มือนี้ใช้ Next.js ที่มี router ในตัว: แต่ละโฟลเดอร์ใน `src/app/` คือที่อยู่หนึ่งหน้า (`src/app/(app)/today/page.tsx` คือ `/today`) แนวคิดเดียวกับ React Router คือ "ที่อยู่ → หน้า" + "โครงหน้าร่วม" (`layout.tsx` ทำหน้าที่เดียวกับ `PublicLayout` + `Outlet`) ส่วนชื่อหน้าตั้งด้วย `metadata` เช่น หน้าวันนี้ตั้ง `title: "วันนี้"`

ข้อจำกัดของเว็บ Vite + React Router ที่ต้องอธิบายลูกค้าได้: server ส่ง HTML ว่างมาก่อน แล้ว JavaScript ค่อยวาดเนื้อหา Google รอวาดได้ แต่แอปแชตบางตัวไม่รอ การ์ดแชร์ลิงก์จึงอาจไม่ขึ้นตามชื่อหน้าที่ตั้งในชิ้นส่วน

ลองคิด: หน้าไหนของงาน STARTER ที่ "ต้อง" ขึ้นใน Google และหน้าไหนที่ไม่ควรขึ้นเลย

## ตัวเลือกอื่นที่คล้ายกัน

| วิธี | ที่อยู่ → หน้า กำหนดที่ | ระดับ |
|---|---|---|
| **React Router (ทีมใช้กับ Vite)** | `<Route path>` ในโค้ด | ใช้กับงาน STARTER |
| Next.js | โฟลเดอร์ใน `app/` และ HTML สร้างฝั่ง server ได้ | ควรรู้จัก เว็บคู่มือนี้ใช้ |
| TanStack Router | ประกาศ route แบบ type ตรวจได้ทุกพารามิเตอร์ | รู้ว่ามี |
| สลับหน้าด้วย state | ไม่มี ที่อยู่ไม่เปลี่ยน | ใช้แค่ป๊อปอัปหรือแท็บย่อยในหน้า |

## ลองเอง

**โจทย์:** ทำ 3 หน้า: รายการหนังสือที่กรองตามหมวดได้ (ตัวกรองอยู่ใน URL), หน้ารายละเอียดหนังสือ `/books/:id` ที่ชื่อแท็บเป็นชื่อหนังสือ และหน้า 404 ที่มีปุ่มกลับหน้าแรก ทุกหน้าใช้เมนูบนชุดเดียวกัน และเมนูของหน้าที่เปิดอยู่ต้องเด่นกว่าเมนูอื่น
