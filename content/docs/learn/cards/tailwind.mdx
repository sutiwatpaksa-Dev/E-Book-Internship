## ความหมาย

[Tailwind](/glossary#tailwind) คือการตกแต่งหน้าเว็บด้วย **คลาสสั้นๆ ที่ทำงานอย่างเดียว** ใส่ตรงในแท็ก เช่น `p-4` (ระยะขอบใน), `rounded-xl` (มุมมน), `text-lg` (ตัวใหญ่) ไม่ต้องเขียนไฟล์ CSS แยกแล้วคิดชื่อคลาสเอง และแต่ละคลาสเติมคำนำหน้าบอกขนาดจอได้ ([breakpoint](/glossary#breakpoint)) เช่น `md:grid-cols-2`

**นึกภาพ:** ตัวต่อเลโก้ แต่ละชิ้นทำได้อย่างเดียว (สี, ระยะ, มุม) เอามาต่อกันในแท็กจนได้หน้าตาที่ต้องการ ไม่ต้องหล่อชิ้นใหม่เอง

## ที่มา

เขียน CSS แยกไฟล์ ใช้ไปนานๆ จะไม่กล้าลบอะไร เพราะไม่รู้ว่าคลาส `.card-title` ยังมีหน้าไหนใช้อยู่ และชื่อคลาสตั้งกันคนละแบบ Tailwind ย้ายการตกแต่งมาอยู่ติดกับแท็ก ลบแท็กก็ลบการตกแต่งไปด้วย ค่าที่ใช้ได้ (ระยะ สี ขนาดตัวอักษร) มีชุดเดียว หน้าเว็บทั้งเว็บเลยดูเป็นชุดเดียวกัน

## การใช้งาน

### ตั้งค่าครั้งแรก (ในโฟลเดอร์ `client/` จากการ์ด [React: Component](/learn/cards/react-components))

```bash
bun add tailwindcss @tailwindcss/vite
```

เพิ่ม plugin ใน `client/vite.config.ts`

```ts
import tailwindcss from "@tailwindcss/vite";
import react from "@vitejs/plugin-react";
import { defineConfig } from "vite";

export default defineConfig({
  plugins: [react(), tailwindcss()],
});
```

ลบไฟล์ `src/App.css` ทิ้ง (และบรรทัด `import "./App.css"` ใน `App.tsx` ถ้ามี) แล้วแทนที่ `src/index.css` ทั้งไฟล์ด้วยข้างล่าง (`main.tsx` import ไฟล์นี้อยู่แล้ว)

**สีและฟอนต์ของโปรเจกต์อยู่ที่เดียว** (Tailwind รุ่น 4)

```css
@import "tailwindcss";

@theme {
  --color-brand: #0b3c91;        /* ได้คลาส bg-brand, text-brand, border-brand */
  --font-sans: "IBM Plex Sans Thai", sans-serif;
}
```

`--font-sans` แค่บอกชื่อฟอนต์ ถ้าเครื่องไม่มีฟอนต์นี้ browser จะใช้ฟอนต์สำรอง ถ้าอยากได้จริงต้องโหลดฟอนต์เพิ่ม (ดูบทเดิม [Tailwind](/12-tailwind))

**เขียนสำหรับมือถือก่อน** คลาสที่ไม่มีคำนำหน้าใช้กับทุกจอ แล้วเติม `sm:` `md:` `lg:` สำหรับจอที่ **กว้างขึ้น**

ลองกับหน้ารายการ: ใน `src/pages/books-page.tsx` เปลี่ยน `<section>...</section>` ที่ return อยู่ เป็น

```tsx
<ul className="grid grid-cols-1 gap-4 md:grid-cols-2 lg:grid-cols-3">
  {books.map((b) => (
    <li key={b.id} className="rounded-xl hover:bg-gray-50">
      <BookCard book={b} />
    </li>
  ))}
</ul>
```

มือถือเห็น 1 คอลัมน์ จอ 768px ขึ้นไปเห็น 2 จอ 1024px ขึ้นไปเห็น 3 (รีสตาร์ท `bun run dev` หลังติดตั้ง แล้วลองย่อหน้าต่าง browser ดู)

| คำนำหน้า | ใช้เมื่อจอกว้างตั้งแต่ |
|---|---|
| (ไม่มี) | ทุกจอ รวมมือถือ 375px |
| `sm:` | 640px |
| `md:` | 768px (แท็บเล็ต) |
| `lg:` | 1024px |
| `xl:` | 1280px (โน้ตบุ๊ก) |

## ทริคที่แนะนำ

1. **`md:` ไม่ได้แปลว่ามือถือ** แปลว่า "ตั้งแต่ 768px ขึ้นไป" อยากซ่อนบนมือถือเขียน `hidden md:block` อยากซ่อนบนจอใหญ่เขียน `md:hidden`
2. **สีใส่ใน `@theme` ไม่ใส่ตรงๆ** `bg-[#0b3c91]` กระจายอยู่ 30 ไฟล์ วันลูกค้าเปลี่ยนสีต้องไล่แก้ 30 ที่ `bg-brand` แก้ที่เดียว และทำโหมดมืดได้ง่าย
3. **ทดสอบที่ 375px ทุกครั้ง** DevTools → ปุ่มรูปมือถือ (Toggle device toolbar) ดูว่าไม่มีอะไรล้นจอ และปุ่มสูงพอให้นิ้วกด (อย่างน้อย 44px)

## ปรับไปใช้จริง

**ในงาน STARTER:** Requirement ตรวจ responsive ที่ 375 / 768 / 1280 px ตรงกับ "ไม่มีคำนำหน้า" / `md:` / `xl:` ในตาราง และวันที่ 6 ต้องตั้ง Tailwind theme (สี, ฟอนต์) ตาม brief ให้เสร็จก่อนทำหน้าแรก

**เว็บคู่มือนี้:** ตกแต่งด้วย Tailwind 4 ทั้งหมด สีหลักตั้งไว้ใน [src/app/global.css](https://github.com/sutiwatpaksa-Dev/E-Book-Internship/blob/main/src/app/global.css) เป็น `--color-fd-primary` ทั้งโหมดสว่างและโหมดมืด ชิ้นส่วนใช้คลาส `bg-fd-primary` `text-fd-primary` ไม่มีรหัสสีตรงๆ ส่วนแถบเมนูล่างบนมือถือ ([section-links.tsx](https://github.com/sutiwatpaksa-Dev/E-Book-Internship/blob/main/src/components/section-links.tsx)) ใช้ `md:hidden` ซ่อนตัวเองบนจอกว้าง

ลองคิด: ตารางกว้าง 6 คอลัมน์บนจอ 375px ควรทำยังไง ย่อตัวหนังสือ เลื่อนซ้ายขวา หรือเปลี่ยนเป็นกล่องเรียงลงมา

## ตัวเลือกอื่นที่คล้ายกัน

| วิธี | หน้าตา | ระดับ |
|---|---|---|
| **Tailwind CSS (ทีมใช้)** | คลาสในแท็ก `className="p-4 md:p-8"` | ใช้ทุกงาน |
| CSS Modules | ไฟล์ `.module.css` ชื่อคลาสไม่ชนข้ามไฟล์ | ควรรู้จัก ใช้ได้ทันทีใน Vite และ Next.js |
| CSS ธรรมดา | ไฟล์ `.css` ทั้งเว็บ | ควรรู้จัก พื้นฐานของทุกวิธี |
| Bootstrap | คลาสสำเร็จรูประดับชิ้น เช่น `btn btn-primary` | รู้ว่ามี เจอในเว็บรุ่นเก่า |

Tailwind ไม่ได้แทนความรู้ CSS: `flex`, `grid`, `padding` ยังเป็นแนวคิดของ CSS ทั้งหมด แค่เขียนสั้นลง

## ลองเอง

**โจทย์:** ทำแถบเมนูบนที่จอกว้างโชว์ลิงก์เรียงแนวนอน แต่บนมือถือมีปุ่ม ☰ กดแล้วเมนูเรียงลงมา ใช้สีหลักจาก `@theme` เท่านั้น แล้วแคปจอที่ 375 / 768 / 1280 px

<Hint level={1}>มีของ 2 ชิ้นที่สลับกันโชว์: ลิงก์แนวนอน กับปุ่ม ☰ แต่ละชิ้นต้องรู้ว่าตัวเองโชว์ที่จอไหน</Hint>
<Hint level={2}>เปิด/ปิดเมนูบนมือถือเป็น state (ดูการ์ด State) ส่วนการซ่อนตามขนาดจอเป็นงานของคลาส ไม่ต้องใช้ JavaScript</Hint>
<Hint level={3}>ปุ่ม ☰ ไม่มีตัวหนังสือ ต้องมี `aria-label` ให้โปรแกรมอ่านหน้าจอรู้ว่าเป็นปุ่มอะไร</Hint>
