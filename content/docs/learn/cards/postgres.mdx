## ความหมาย

Postgres (ชื่อเต็ม PostgreSQL) คือ **โปรแกรมที่เก็บข้อมูลและตอบคำสั่ง SQL** เรียกรวมๆ ว่า DBMS เวลาพูดว่า "ฐานข้อมูล" ในงานจริง ต้องแยกให้ออกเป็น 3 ส่วน:

| ส่วน | คืออะไร | ตัวอย่าง |
|---|---|---|
| Engine | โปรแกรมฐานข้อมูล | Postgres, MySQL |
| ที่ที่รัน | เครื่องที่เปิดโปรแกรมนั้นไว้ | Docker ในเครื่องเรา, Neon บนคลาวด์ |
| Client | โปรแกรมที่เราใช้ต่อเข้าไปดู | `psql`, pgAdmin, DBeaver |

## ที่มา

เริ่มจากโปรเจกต์วิจัย POSTGRES ที่ UC Berkeley ช่วงกลางทศวรรษ 1980 ต่อมาเพิ่มภาษา SQL และเปลี่ยนชื่อเป็น PostgreSQL ในปี 1996 เป็นโอเพนซอร์สที่ไม่มีบริษัทเดียวเป็นเจ้าของ จึงมีผู้ให้บริการหลายเจ้าให้เลือก ย้ายค่ายได้ง่าย

## การใช้งาน

เปิด Postgres ในเครื่องด้วย Docker (พิมพ์เหมือนกันทั้ง Windows และ Mac):

```bash
docker run -d --name pg -e POSTGRES_PASSWORD=secret -p 5432:5432 postgres:17
```

แล้วโค้ดต่อเข้าไปด้วย **connection string** หน้าตาแบบนี้:

```
postgres://postgres:secret@localhost:5432/postgres
           ผู้ใช้  :รหัส  @เครื่อง  :port/ชื่อฐาน
```

## ทริคที่แนะนำ

1. **port ชนกัน** (`port is already allocated`) แปลว่ามี Postgres ตัวอื่นจับ 5432 อยู่ เปลี่ยนฝั่งซ้ายเป็น `-p 5433:5432` แล้วแก้ port ใน connection string ให้ตรง
2. **อยากให้ข้อมูลอยู่ต่อหลังลบกล่อง** เพิ่ม volume: `-v pgdata:/var/lib/postgresql/data` ไม่งั้น `docker rm` แล้วข้อมูลหายด้วย
3. **connection string มีรหัสผ่าน** เก็บใน `.env` เสมอ ห้าม commit ขึ้น Git

## ปรับไปใช้จริง

เว็บคู่มือนี้ใช้ Postgres ทั้งสองที่: ในเครื่องใช้ Docker (`postgres:17-alpine`) ส่วนเว็บจริงใช้ Neon บนคลาวด์ โค้ดเหมือนกันทุกบรรทัด ต่างกันแค่ค่า `DATABASE_URL` ใน env นี่คือข้อดีของการแยก "engine" กับ "ที่ที่รัน"

ลองคิด: โปรเจกต์ของเราตอน deploy จะให้ Postgres รันที่ไหน แลกกับอะไร (ดูแลเอง หรือจ่ายให้คนอื่นดูแล)

## ลองเอง

**โจทย์:** เปิด Postgres ใน Docker ให้ข้อมูลอยู่รอดหลัง `docker rm -f pg` แล้วสร้างกลับมาใหม่ พิสูจน์ด้วยตาราง `members` ที่มีข้อมูล 2 แถว

<Hint level={1}>ข้อมูลหายตอนลบกล่องเพราะเก็บไว้ในกล่อง ต้องให้มันเก็บไว้ที่อื่นที่ไม่หายไปพร้อมกล่อง</Hint>
<Hint level={2}>ดูทริคข้อ 2 แล้วใช้ client ตัวไหนก็ได้สร้างตารางและเพิ่มข้อมูล</Hint>
<Hint level={3}>ลำดับ: `docker run` (มี volume) → สร้างตาราง + 2 แถว → `docker rm -f pg` → `docker run` คำสั่งเดิม → `SELECT` ดูว่ายังอยู่ไหม</Hint>
