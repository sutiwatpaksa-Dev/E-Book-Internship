## ความหมาย

SQL คือ **ภาษากลางที่ใช้สั่งงานฐานข้อมูลแบบตาราง** บอกว่าอยากได้ข้อมูลแบบไหน แล้วฐานข้อมูลไปหาวิธีเอง เหมือนบอกบรรณารักษ์ว่า "ขอหนังสือที่ยังไม่มีคนคืน" โดยไม่ต้องบอกว่าเดินไปชั้นไหน

## ที่มา

ก่อนมี SQL แต่ละโปรแกรมเก็บข้อมูลในรูปแบบของตัวเอง จะดึงข้อมูลทีต้องเขียนโปรแกรมไล่อ่านไฟล์เอง ช่วงทศวรรษ 1970 นักวิจัยของ IBM ออกแบบภาษาที่ "บอกสิ่งที่อยากได้" บนแนวคิดตารางที่โยงกันได้ (relational model) ต่อมากลายเป็นมาตรฐาน ฐานข้อมูลเกือบทุกค่ายจึงพูดภาษาเดียวกัน ต่างกันแค่สำเนียงเล็กน้อย

## การใช้งาน

คำสั่งหลักมี 4 คำ: `SELECT` อ่าน, `INSERT` เพิ่ม, `UPDATE` แก้, `DELETE` ลบ ส่วนที่ใช้คู่กันบ่อยคือ `WHERE` (เลือกแถว) และ `JOIN` (เอาตารางที่โยงกันมาต่อกัน)

ตัวอย่างระบบห้องสมุด: ใครยืมหนังสืออะไรอยู่บ้าง

```sql
SELECT members.name, books.title
FROM loans
JOIN members ON members.id = loans.member_id
JOIN books   ON books.id   = loans.book_id
WHERE loans.returned_at IS NULL;
```

อ่านจากล่างขึ้นบนจะเข้าใจง่าย: เอาการยืมที่ยังไม่คืน → ต่อกับตารางสมาชิกและหนังสือ → เลือกแค่ชื่อกับชื่อเรื่อง

> พิมพ์ลองได้ใน `psql` ที่รันใน Docker คำสั่งเหมือนกันทั้ง Windows (PowerShell) และ Mac (Terminal): `docker exec -it pg psql -U postgres` (ดูวิธีเปิด Postgres ในการ์ด [Postgres และที่ที่มันรัน](/learn/cards/postgres))

## ทริคที่แนะนำ

1. **ก่อน `UPDATE` หรือ `DELETE` ให้ `SELECT` ด้วย `WHERE` เดียวกันก่อน** ดูว่าโดนกี่แถว ลืม `WHERE` = แก้หรือลบทั้งตาราง
2. **ทดลองใน transaction:** พิมพ์ `BEGIN;` ก่อน ลองคำสั่ง แล้ว `ROLLBACK;` ถ้าผลไม่ใช่ ข้อมูลกลับเหมือนเดิม
3. **ห้ามเอาข้อความจากผู้ใช้ต่อเป็นคำสั่ง SQL ตรงๆ** ใช้ตัวแปร (`$1`) ให้ library ส่งค่าแยก ไม่งั้นโดน SQL Injection (ดูในบท [Security](/10-security))

## ปรับไปใช้จริง

ในโค้ดของทีมเราแทบไม่ได้พิมพ์ SQL เอง เพราะใช้ Drizzle สร้างให้ แต่ **ยังต้องอ่าน SQL ออก** เพราะไฟล์ migration เป็น SQL ล้วน (ดูของจริงในเว็บนี้ที่ `server/db/migrations/*.sql`) และเวลาเครื่องมือทำงานผิด error ที่ได้ก็เป็นภาษา SQL

ลองคิด: ในโปรเจกต์ของเรา หน้าไหนต้องใช้ข้อมูลจากมากกว่า 1 ตาราง (หน้านั้นจะต้องใช้ `JOIN`)

## ตัวเลือกอื่นที่คล้ายกัน

SQL ใช้ได้กับฐานข้อมูลแบบตารางเกือบทุกตัว ต่างกันที่สำเนียงและความสามารถเสริม ถ้าไม่อยากพิมพ์ SQL เองในโค้ด ดูการ์ด [ORM กับ Query Builder](/learn/cards/orm-query-builder)

## ลองเอง

**โจทย์:** หาสมาชิกที่ยืมหนังสือ **เกินกำหนด** (ถึงวันคืนแล้วยังไม่คืน) เรียงจากเกินนานที่สุด

<Hint level={1}>ต้องมีคอลัมน์ "วันที่ต้องคืน" ในตาราง `loans` ก่อน แล้วคิดว่า "เกินกำหนด" แปลเป็นเงื่อนไขกี่ข้อ</Hint>
<Hint level={2}>Postgres มีฟังก์ชัน `now()` ให้เวลาปัจจุบัน และเรียงผลด้วย `ORDER BY`</Hint>
<Hint level={3}>โครง: `SELECT ... FROM loans JOIN members ON ... WHERE <ยังไม่คืน> AND <เลยวันคืน> ORDER BY <คอลัมน์วันคืน>` เติมช่องเอง</Hint>
