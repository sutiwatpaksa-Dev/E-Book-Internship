## ความหมาย

React สร้างหน้าเว็บจาก **ชิ้นส่วน (component)** ชิ้นส่วนคือฟังก์ชันที่ **รับข้อมูลเข้า (props) แล้วคืนหน้าตา** เขียนหน้าตาด้วย **JSX** ซึ่งหน้าตาเหมือน HTML แต่อยู่ในไฟล์ TypeScript (`.tsx`) และแทรกค่าด้วย `{ }`

## ที่มา

เขียน HTML ล้วน ถ้ามีหนังสือ 20 เล่มต้องก๊อปกล่อง 20 ก้อน พอแก้หน้าตากล่องต้องตามแก้ 20 ที่ และข้อมูลที่มาจาก API ก็ต้องเขียน JavaScript ไปสร้างกล่องเองทีละชิ้น React (Meta เปิดเป็น open source ปี 2013) ให้เราเขียนกล่องครั้งเดียวเป็นชิ้นส่วน แล้ว **บอกว่าข้อมูลแบบนี้ควรหน้าตาแบบไหน** ส่วนการสร้างและอัปเดตหน้าจอจริงเป็นงานของ React

## การใช้งาน

```tsx
// src/components/book-card.tsx
export type Book = { id: number; title: string; available: boolean };

export function BookCard({ book }: { book: Book }) {
  return (
    <article className="rounded-xl border p-4">
      <h3>{book.title}</h3>
      {book.available ? <p>ยืมได้</p> : <p>ถูกยืมอยู่</p>}
    </article>
  );
}
```

```tsx
// src/pages/books-page.tsx
import { BookCard, type Book } from "../components/book-card";

export function BooksPage({ books }: { books: Book[] }) {
  if (books.length === 0) return <p>ยังไม่มีหนังสือ</p>;
  return (
    <section>
      {books.map((b) => (
        <BookCard key={b.id} book={b} />
      ))}
    </section>
  );
}
```

ต่างจาก HTML 3 จุดที่เจอบ่อย: ใช้ `className` แทน `class`, ทุกแท็กต้องปิด (`<img />`), และคืนได้ก้อนเดียว (หลายก้อนให้ห่อด้วย `<>...</>`)

## ทริคที่แนะนำ

1. **ทุกรายการที่ `.map` ต้องมี `key` ที่ไม่ซ้ำและไม่เปลี่ยน** ใช้ id จากฐานข้อมูล อย่าใช้ลำดับ (index) เพราะพอลบหรือเรียงใหม่ React จะจับคู่ชิ้นผิด ช่องกรอกในรายการจะสลับค่ากัน
2. **props ไหลทางเดียว จากแม่ลงลูก** ลูกห้ามแก้ props ตัวเอง อยากให้ลูกบอกแม่ ให้ส่งฟังก์ชันลงไป เช่น `onBorrow={() => ...}`
3. **แยกชิ้นเมื่อมีเหตุผล:** ใช้ซ้ำหลายที่ หรือไฟล์ยาวจนอ่านไม่จบในหน้าจอเดียว ไม่ต้องแยกทุก `<div>`

## ปรับไปใช้จริง

เว็บคู่มือนี้สร้างด้วย React ทั้งหมด เปิด `src/components/step-cards.tsx` จะเห็นการ์ดในหน้าขั้นเป็นชิ้นส่วนที่รับ `step` เข้ามาแล้ว `.map` เป็นรายการ โดยใช้ `slug` ของการ์ดเป็น `key` ส่วนหน้าตาที่เปลี่ยนตามข้อมูล (วงกลมติ๊กถูกเมื่อเข้าใจแล้ว) ใช้ `isDone ? ... : ...` แบบเดียวกับตัวอย่างข้างบน

ลองคิด: หน้า "คลังการ์ด" มีกล่องการ์ดหน้าตาเดียวกับหน้าขั้น ควรเป็นชิ้นส่วนเดียวกันไหม ถ้าวันหนึ่งสองหน้าต้องหน้าตาต่างกัน จะทำยังไง

## ตัวเลือกอื่นที่คล้ายกัน

| ตัว | เขียนหน้าตาด้วย | ระดับ |
|---|---|---|
| **React (ทีมใช้)** | JSX ในไฟล์ `.tsx` | ใช้ทุกงาน คนใช้และตัวอย่างมากที่สุด |
| Vue | template ในไฟล์ `.vue` | ควรรู้จัก เจอในงานลูกค้าหลายเจ้า |
| Svelte | template ที่ถูกแปลงเป็น JavaScript ตอน build | รู้ว่ามี |
| Angular | template + TypeScript มีโครงใหญ่ครบในตัว | รู้ว่ามี เจอในองค์กรใหญ่ |

แนวคิดชิ้นส่วน + ข้อมูลเข้า + หน้าตาเปลี่ยนตามข้อมูล เหมือนกันทุกตัว ย้ายค่ายได้ไม่ต้องเริ่มใหม่

## ลองเอง

**โจทย์:** ทำหน้ารายชื่อสมาชิกห้องสมุดที่แสดงชื่อ จำนวนเล่มที่ยืมอยู่ และป้าย "ยืมครบแล้ว" สีแดงเมื่อยืมครบ 3 เล่ม ถ้าไม่มีสมาชิกเลยต้องขึ้นข้อความแทนรายการว่าง

<Hint level={1}>เริ่มจากกล่องของสมาชิก 1 คน ให้ใช้ได้ก่อน แล้วค่อยทำรายการ</Hint>
<Hint level={2}>ป้ายที่ขึ้นบ้างไม่ขึ้นบ้าง ใช้ `{เงื่อนไข && <span>...</span>}`</Hint>
<Hint level={3}>ลองลบสมาชิกคนแรกออกจาก array แล้วดูว่า DevTools Console มีเตือนเรื่อง `key` ไหม ถ้ามีแปลว่ายังไม่ได้ใส่หรือใส่ซ้ำ</Hint>
