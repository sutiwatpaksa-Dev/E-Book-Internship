## ขั้นนี้คืออะไร

ย้ายระบบจากเครื่องเราไปไว้บนเครื่องที่เปิดตลอดเวลา แล้วให้คนอื่นเปิดได้จาก URL จริง มีสองทางหลัก: **บริการสำเร็จรูป** (เช่น Vercel + Neon ดูแลเครื่องให้) กับ **เช่าเครื่องเอง** (VPS ดูแลเองทั้งหมด)

## ถ้าทำไม่ครบจะเกิดอะไร

บิตขึ้นเว็บสำเร็จ แต่ลืมรัน migration กับฐานข้อมูลจริง เปิดหน้าแรกได้ กดสมัครสมาชิกแล้ว error เพราะไม่มีตาราง **deploy ไม่ได้จบที่ "เว็บเปิดได้" แต่จบที่ "งานหลักใช้ได้จริง"**

## จบขั้นแล้วต้องมี

- [ ] เว็บเปิดได้จาก URL จริงผ่าน https
- [ ] ค่า env ตั้งบน server ครบ ไม่มีค่าลับใน repo
- [ ] ฐานข้อมูลจริงรัน migration แล้ว
- [ ] ลองทำงานหลักทุกข้อบนเว็บจริงตามเช็กลิสต์จากขั้น 4
- [ ] รู้ว่าถ้าต้องถอยกลับเวอร์ชันก่อน ทำยังไง

## คำถามที่ต้องตอบได้

1. ทำไมเลือกบริการสำเร็จรูปหรือเช่าเครื่อง แลกกับอะไร
2. ค่า env บนเครื่องจริงต่างจากในเครื่องเราตรงไหน
3. ถ้า deploy แล้วพัง จะดู error ได้ที่ไหน
