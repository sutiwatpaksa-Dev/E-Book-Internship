## ขั้นนี้คืออะไร

หลังเปิดใช้จริง งานยังไม่จบ ต้อง **รู้ตัวเมื่อระบบพัง กู้ข้อมูลได้เมื่อเกิดเรื่อง และอัปเดตโดยไม่ทำให้ผู้ใช้เดือดร้อน** bug และ feedback ที่ได้จากผู้ใช้คือ "ปัญหาใหม่" ที่วนกลับไปเริ่มขั้น 1 อีกรอบ

## ถ้าข้ามขั้นนี้จะเกิดอะไร

ร้านค้าแจ้งว่าออเดอร์เมื่อวานหายหมด บิตเพิ่งรู้ว่าไม่เคยตั้ง backup และไม่มี log ให้ดูว่าเกิดอะไรขึ้น **backup ที่ไม่เคยลองกู้คืน เท่ากับไม่มี backup**

## จบขั้นแล้วต้องมี

- [ ] ที่ดู log และวิธีอ่าน error บนเครื่องจริง
- [ ] backup ฐานข้อมูลอัตโนมัติ และ **เคยลองกู้คืนจริงแล้ว 1 ครั้ง**
- [ ] รอบอัปเดต dependency และวิธีเช็กแจ้งเตือนช่องโหว่
- [ ] ช่องทางรับ feedback จากผู้ใช้ และวิธีจดเป็นงานใหม่

## คำถามที่ต้องตอบได้

1. ถ้าเว็บล่มตอนตี 2 ใครจะรู้ก่อน เรา หรือลูกค้า
2. ข้อมูลหายย้อนหลังได้ไม่เกินกี่ชั่วโมง
3. อัปเดต library ครั้งล่าสุดเมื่อไหร่
