## ขั้นนี้คืออะไร

เปลี่ยนแบบจากขั้น 2 เป็นระบบที่รันได้ในเครื่อง แบ่งเป็น 6 ช่วง เรียงตามวันในงาน STARTER และทำ **จากข้างในออกมาข้างนอก**

| ช่วง | วันใน STARTER | ทำอะไร | ตรวจได้ยังไงว่าเสร็จ |
|---|---|---|---|
| เตรียมเครื่อง | วันที่ 1 | ติดตั้งเครื่องมือ, Git, โครง `client/` + `server/` | `bun run dev` ทั้งสองฝั่งขึ้น |
| DB | วันที่ 2 | สร้างตารางด้วย migration + seed | เปิดดูข้อมูลใน pgAdmin ได้ |
| API | วันที่ 3 | endpoint, ตรวจข้อมูลด้วย Zod, กฎของระบบ, รูปแบบ error | ยิง Postman ได้ครบ ได้ `{ success, data }` |
| Login | วันที่ 4 | login หลังบ้าน, hash รหัสผ่าน, ด่านตรวจ API หลังบ้าน | ยิง API หลังบ้านโดยไม่ login ได้ `401` |
| Frontend | วันที่ 6–7 | หน้าเว็บที่ดึงข้อมูลจาก API, ฟอร์มติดต่อ | กดบนเว็บแล้วข้อมูลในฐานเปลี่ยนจริง |
| หลังบ้าน | วันที่ 8 | หน้าจัดการข้อมูล (เพิ่ม แก้ ลบ) | admin แก้ข้อมูลแล้วหน้าบ้านเปลี่ยนตาม |

**ทำไมเริ่มจากข้างใน:** ทุกช่วงพึ่งช่วงก่อนหน้า ถ้าตารางยังไม่นิ่ง API กับหน้าเว็บก็ต้องแก้ตาม และแต่ละช่วงตรวจได้โดยไม่ต้องรอช่วงถัดไป เช่น ทดสอบ API ด้วย Postman ได้ทั้งที่ยังไม่มีหน้าเว็บ

> วันที่ 5, 9, 10 ไม่อยู่ในตาราง เพราะเป็นวัน review, ขัดเกลา (SEO, rate limit) และส่งงาน ซึ่งอยู่ในขั้น Testing, Documentation และ Deploy ส่วนการ์ดแต่ละใบบอกไว้บนหัวการ์ดว่าใช้ในวันไหน

> ทำหน้าเว็บไปก่อนแล้วก็ไม่เป็นไร ข้อมูลตัวอย่างที่หน้าเว็บใช้คือแบบตารางชั้นดี ดูวิธีเริ่มจากของที่มีใน [ทำหน้าเว็บเสร็จก่อนแล้ว เริ่ม server ตรงไหน](/14-hono-api#ทำหน้าเว็บเสร็จก่อนแล้ว-เริ่ม-server-จากของที่มี)

## ถ้าข้ามลำดับจะเกิดอะไร

บิตเขียนทุกชั้นพร้อมกันทีเดียว พอกดปุ่มแล้วไม่มีอะไรเกิดขึ้น ไม่รู้ว่าพังที่หน้าเว็บ API หรือฐานข้อมูล **ทำทีละช่วงและตรวจทีละช่วง ทำให้รู้เสมอว่าพังที่ชั้นไหน**

## จบขั้นแล้วต้องมี

- [ ] ตารางทั้งหมดสร้างด้วย migration (ไม่ได้สร้างด้วยมือ)
- [ ] API ทุกตัวในรายการจากขั้น 2 อยู่ใน Postman collection และยิงแล้วได้ผลตามที่ออกแบบ
- [ ] หน้าเว็บใช้ข้อมูลจริงจาก API (ไม่มีข้อมูลตัวอย่างค้างอยู่)
- [ ] งานอยู่ใน Git แบ่ง commit ตามงานย่อย

## คำถามที่ต้องตอบได้

1. ถ้ามีคนยิง API ตรงๆ ข้ามหน้าเว็บ กฎของระบบยังทำงานไหม (กฎควรอยู่ที่ Backend ไม่ใช่หน้าเว็บ)
2. ข้อมูลเดินทางจากปุ่มบนหน้าเว็บไปถึงตารางผ่านไฟล์ไหนบ้าง
3. ถ้าต้องเพิ่มคอลัมน์ใหม่ ต้องแก้ไฟล์ไหนบ้าง ตามลำดับไหน
